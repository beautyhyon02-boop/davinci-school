# 문항 제작소(2주차) 설계

작성일: 2026-09-20 · 상위 스펙: `2026-09-18-davinci-school-website-design.md` §5 (이 문서가 §5를 대체·구체화)
근거 자료: `docs/research/2026-09-19-essay-item-format.md`(공통작성양식), `…-essay-course-method.md`(전문가 과정 2기), `…-ebs-item-design.md`(EBS)

## 1. 본사가 내려보내는 "패키지"

대주제 1개 × 과목별 **문항 세트** = 원장님이 전공과 무관하게 4~6차시 수업 후 평가까지 할 수 있는 완성품.

| 구성 | 내용 |
|---|---|
| 표지 | 과목·학교급·학년(성취기준 기준, 예: 중1)·단원·예상 차시·작성일·버전 |
| 성취기준 원문 | DB의 **검증된** 원문만 참조 (코드·원문·관련 핵심역량). **세트 = 소단원 하나**(예: 자료의 정리와 해석 3개, 정수와 유리수 3개), 2~6개. 대주제는 자료·맥락으로 녹인다 |
| 재구성 | 원문 어휘를 보존하며 관련 성취기준을 한 문장으로 통합 (EBS 방식). **원문에 없는 동사·대상·내용 금지** |
| 학습 목표 | 3~4개, "~할 수 있다" 한 문장씩. 차시와 문항의 뼈대 |
| 핵심질문 | **두 층**: ① 세트 핵심질문 1개(논술형과 전체 차시를 관통) ② 차시 핵심질문(차시마다 1개, 그 차시가 담당하는 성취기준 1~2개에서 도출). 사실 확인형 금지, 자료를 근거로 판단해야 답할 수 있는 형태 |
| 차시 설계 | 4~6차시(성취기준 수 ÷ 1~2로 정해짐), 1차시 = 1시간 (학원 2시간 등원 = 2차시 연속). 앞부분이 쉬우면 원장님이 **차시를 당겨 합쳐 진행할 수 있도록** 각 차시에 "○차시와 병합 가능" 표시와 병합 시 생략 가능 활동을 지침서에 명시. 차시마다 **담당 성취기준 1~2개**·차시 핵심질문·목표·활동 흐름·자료·**마무리 퀴즈 3문항**(차시 핵심질문 점검, 객관식/단답, 정답·해설 포함) |
| 교사용 지침서 | 차시마다 준비물, 도입 발문, 전개 순서, 정리, 퀴즈 해설, **비전공 원장님 주의점** |
| 자료 | 본사가 문항에 맞춰 **생성한 가상 자료**(지문·표·데이터). 저작권 = 자작. **대주제의 모든 과목이 같은 자료 A~D를 공유**(STEAM). 표·그래프(히스토그램·상대도수 막대 등)는 **데이터에서 자동 생성**(SVG)하여 수치와 그림이 어긋나지 않게 한다. 삽화·도식은 자료·차시마다 **이미지 첨부 슬롯**을 두고 관리자가 붙인다(Canva MCP로 만든 이미지 등). 학생 직접 조사로 대체 가능함을 지침서에 표기 |
| 평가 문항 세트 | 서술형 2개(해당 차시 끝) + 논술형 1개(마지막 차시 전체). 문두 = 조건+평가요소+기능+배점. 응답 조건(분량/필수요소/형식) |
| 채점기준 | **문항마다** 작은 표: 평가요소 · 배점 · 수준별 기대 수행 + 그 수준의 예시답안 내장. 서술형은 2~3단계, 논술형은 요소별 4구간 서술어(MYP) |
| 등급 경계표 | 세트 총점 → **1~7등급**(MYP식) + 학부모 표시용 상(6~7)/중(3~5)/하(1~2) |
| 예시답안 | 논술형에 대해 상/중/하 전문 (어느 등급에 해당하는지 명시). 서술형은 채점표 안에 내장 |
| 피드백 문구 틀 | 채점 후 학생에게 주는 상/중/하 1~2문장 틀 (AI 채점 시 개인화의 기준) |

**규칙**
- 선행 여부는 원마다 다르므로 세트는 **교육과정 학년 하나만** 기준으로 만든다. 어휘·자료·지침서·평가 모두 그 학년(예: 중1) 수준. 어느 학년 학생에게 쓸지는 원장님이 정한다.
- 한 대주제 안의 모든 과목 세트는 **같은 학년**. 대주제에 학년을 먼저 고정하고 세트가 물려받는다. 중학교 국·영·사·과의 성취기준은 1~3학년군이므로 AI는 "그 학년 교과서에서 다루는 내용"만 고르고, 검토 AI가 학년 적합성을 별도 점검하며, 관리자가 최종 확인.
- 과목: 국어·영어·수학·과학·사회·**한국사·세계사** (세계사 추가). 중1 대주제에는 역사 과목이 없을 수 있음(중1은 보통 사회) — 역사 세트는 학년에 역사 수업이 있을 때만.
- 게시 후 수정은 새 버전. 배정된 과제는 배정 당시 버전 고정 (`item_set_versions` 스냅샷).

## 2. 제작 파이프라인 (관리자 화면)

각 단계는 독립된 Claude 호출이고 결과는 저장된다. 관리자는 단계마다 수정 가능, [다음]을 눌러야 확정.

| 단계 | 관리자 | AI (Claude) | 검토 AI |
|---|---|---|---|
| 0 대주제 | 제목·학교급·**학년**·참여 과목 입력 | 소개문 + 과목별 연결 아이디어 한 줄 | — |
| 1 성취기준 | 과목·소단원 선택 → 그 소단원의 성취기준 목록(2~6개) 확인, 필요 시 제외. **원문 확인 체크 필수**(PDF 쪽 표시) | 대주제·학년에 맞는 성취기준 추천 (학년 교과서 내용 기준) | 학년 적합성 |
| 2 재구성·학습목표·핵심질문 | 수정·확정 | 재구성 문장(원문 어휘 보존, 통합형) + 학습 목표 3~4 + 세트 핵심질문 후보 2~3 | **원문 이탈 검사**(원문에 없는 동사·대상·개념 → 반려), 핵심질문이 사실확인형이면 반려 |
| 3 차시 설계 | 차시 수 조정, 성취기준↔차시 배정 확인, 수정 | 차시별 담당 성취기준·차시 핵심질문·목표·활동·자료 계획·퀴즈 3문항, 서술형 문항 배치 | 모든 성취기준이 어느 차시엔가 배정됐는지, 퀴즈가 차시 핵심질문을 점검하는지, 퀴즈 정답 검증 |
| 4 자료 생성 | 확인·수정 | 차시·문항에 필요한 가상 자료(지문·표·수치) 생성. 수치 자료는 내부 일관성(합계 등) 검증 | 자료가 사고를 대신하지 않는지, 학년 어휘 수준 |
| 5 평가 세트 (자동 반복) | 최종본 검토·수정 | 문두(조건+평가요소+기능+배점)·응답조건 → 문항별 채점표 → 논술형 예시답안 상/중/하 → 등급 경계표 → 피드백 틀 | 채점표로 예시답안을 실제 채점해 상/중/하가 갈리는지, 배점 합계, 성취기준 이탈, 학년 수준. 실패 시 1로 회귀, 최대 3회 |
| 6 교사용 지침서 | 수정 | 차시별 지침서 | 비전공자가 따라 할 수 있는 구체성 |
| 7 게시 | [게시] → 버전 스냅샷 | — | — |

"기본값으로 진행" 버튼: 한 과목을 추천값으로 자동 통과 (관리자는 최종본만 검토).

## 3. AI 호출 설계

- SDK: `@anthropic-ai/sdk` (TypeScript). 모델: 생성·검토 모두 **`claude-opus-5`**(adaptive thinking, effort `high`; 5단계 반복은 `xhigh`). 채점(3주차)은 `claude-sonnet-5`.
- 모든 출력은 **구조화 출력**(`output_config.format` + zod 스키마)으로 받아 DB jsonb에 저장. 자유 텍스트 파싱 없음.
- 시스템 프롬프트(단계별 고정 부분)에 **캐시 브레이크포인트**: 작성 규칙(공통양식·EBS 규칙·핵심질문 패턴표·재구성 금지 규칙)은 매 호출 동일 → `cache_control`.
- 검토 AI는 생성 AI와 **다른 호출**(같은 모델, 다른 시스템 프롬프트 "검토자"). 검토 결과는 `{pass, issues[]}`로 받아 저장(생성 로그).
- 스트리밍: 5단계 반복은 길어질 수 있어 서버 액션 대신 **route handler + 진행 상태 polling**(단계별 상태를 DB에 기록, 화면은 3초마다 조회).
- 비용 기록: 호출마다 `input/output/cache_read` 토큰을 `generation_log`에 저장.
- 오류: `refusal`/`max_tokens` 처리, API 오류는 단계 상태 `failed`로 저장하고 관리자가 [다시 시도].

## 4. 데이터 변경

- `subject` enum에 `세계사` 추가. 기존 역사 92건을 별책7 영역 기준으로 한국사/세계사 재분류(2주차 작업).
- `standards`에 `verified_at`, `verified_by`, `source_page` 추가. 미검증은 배지 표시, 게시 시 검증된 것만 허용.
- `themes`: `grade` 필수(이미 있음). `item_sets`에 단계별 jsonb: `learning_goals`, `lessons`(차시·퀴즈), `materials`, `items`(문두·조건·채점표), `grade_boundaries`, `feedback_templates`, `teacher_guide`, `stage_status`(단계별 상태·오류).
- `item_set_versions(item_set_id, version, snapshot jsonb, published_at)` 신설. `assignments.item_set_version`은 이 표를 참조.
- `generation_log`: 단계·모델·토큰·검토 결과·회차.

## 5. 첫 세트 (시연 기준)

중1 · "학교 축제 일회용품 줄이기" · 국어·영어·수학·과학·사회 5과목 (역사는 중1에 없음).
수학은 소단원 '자료의 정리와 해석' [9수04-02]+[9수04-03]+[9수04-04]. 초안은 이 문서와 함께 대표님과 확정한 골격(서술형 2 + 논술형 1, 5차시, 가상 자료)을 따른다.

## 6. 2주차 완료 기준

1. 관리자가 제작소에서 0~7단계를 거쳐 **중1 수학 세트를 게시**할 수 있다 (실제 Claude 호출).
2. 재구성 원문 이탈 검사가 동작한다 (의도적으로 이탈시킨 입력을 반려).
3. 게시된 세트가 원장님 화면 "문항 찾기"에 대주제/과목으로 보이고 미리보기(차시·지침서·문항·채점표)가 열린다.
4. 성취기준 검증 표시와 세계사 분리가 반영된다.
5. 나머지 4과목은 "기본값으로 진행"으로 뽑아 대표님이 검토 (품질 확인은 3주차 초까지 이어질 수 있음).

## 7. 범위 밖 (3주차 이후)
학생 퀴즈 응시·자동 채점, 서논술 답안 AI 채점·피드백, 원장 배정, hwp 내보내기.
