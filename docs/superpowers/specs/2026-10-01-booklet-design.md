# 제본용 교재(학생용 교재·교사용 지도서) 설계

- 결정일: 2026-10-01 (대표)
- 시한: 설명회 2026-10-18 — 학생용 교재와 교사용 지도서 모두
- 종이: A4, 양면 인쇄 여백. 학생용 교재에 퀴즈를 넣는다(종이로 푸는 학원용).

## 1. 목적

게시된 세트 하나를 **책 한 권**으로 인쇄한다 — 표지·차례·쪽 번호가 있고 차시마다 새 쪽에서 시작한다. 화면 카드를 그대로 찍는 것이 아니라 인쇄용 판을 따로 그린다.

## 2. 두 권

### 학생용 교재 (답 없음)
1. 표지: 대주제, 과목, 세트 제목, 학교급, 학년 반 번호 이름 쓰는 줄
2. 차례
3. 이 단원에서: 핵심질문, 배울 것(학습목표를 학생 말로 — 이미 있는 학생용 표현 사용), 평가 요소(채점 요소 이름·만점 — 학생에게 보이는 범위만)
4. 차시마다(1~5): 차시 제목·배울 내용 한 줄 → 이 차시 자료(인라인, 공동 자료는 세트가 고른 것만; 영어 세트는 영어판만) → 활동지(과제 + 쓰는 칸, 정답 없음) → 퀴즈 3문항(답 쓰는 줄, 정답·해설 없음)
5. 단원 평가: 문제지와 같은 내용(자료 인라인, 문항, 조건, 평가 요소, 답란 10줄/20줄)
6. 뒤표지(비움 또는 안내 문구)

### 교사용 지도서 (답 있음)
1. 표지(「교사용」 표시)
2. 차례
3. 단원 계획: 성취기준(원문·재구성), 학습목표(3차원), 핵심질문, 차시 구성표(차시·주제·자료·평가)
4. 차시마다: 수업 흐름(도입·전개·정리, 시간) → 교사 발문과 예상 답(발문 아래 줄에) → 활동지와 정답·예시 답 → 퀴즈 정답·해설·역량 → 막힐 때 도움말(if_stuck) → 준비물·유의점
5. 단원 평가: 문항 + 조건 + 채점 기준(분석적·총체적 루브릭) + 예시 답안 + 수준 지도(level_map) + 출제 의도
6. 교사용 지침 전체(영어 세트는 영문 자료 번역 포함)
7. 안내장 틀(차시별 요약·퀴즈 코멘트·채점 요소 문구)

## 3. 인쇄 규칙
- `@page` A4, 여백 안쪽 20mm·바깥 15mm 정도(양면), 쪽 번호 아래 가운데(브라우저가 지원하면 `@page` margin box, 아니면 각 쪽 하단에 그린다 — 지원 확인 뒤 결정).
- 표지·차례·각 차시·단원 평가·지침·안내장 틀은 새 쪽에서 시작. 자료·문항·루브릭은 중간에서 잘리지 않게(`break-inside: avoid`), 긴 것은 자연스럽게 넘어간다.
- 학생용은 흑백 인쇄를 전제로 한다(색으로만 구분하지 않는다). 표는 괘선.
- 글자: 본문 10.5pt, 제목 위계는 크기·굵기로. 세로 목록, 한 줄에 하나.

## 4. 어디서
- 원장: 문항 찾기 → 세트 → [학생용 교재 인쇄] [교사용 지도서 인쇄] (각각 인쇄 전용 쪽으로 열림 → 브라우저 인쇄)
- 본사: 세트 화면에 같은 두 단추(게시 판 기준; 초안은 미리보기 표시)
- 학생·학부모에게는 보이지 않는다(교사용 지도서는 원장·본사만).

## 5. 데이터
- 게시 판 스냅숏(`SnapshotV2`, `upgradeSnapshot`)만 쓴다. 새 테이블·마이그레이션 없음.
- 옛 판(v1 구조)도 깨지지 않게 — 있는 것만 그린다.

## 6. 범위 밖
- 소책자 접지 순서(2쪽 모아 찍기), B5, PDF 파일 자동 생성, 표지 디자인 꾸미기.
