# 교과융합 탐구보고서 설계

- 결정일: 2026-09-30 (대표)
- 시한: 설명회 2026-10-18 시연에 1차 범위 포함
- 자료 후보: `docs/research/2026-09-30-inquiry-sources-일회용품.md`

## 1. 목적

다빈치스쿨 본사는 탐구보고서 작성법을 제공하는 회사다. 서논술 세트(차시 설계·교사용 지침)를 쓰지 않는 원장도 쓸 수 있도록,
2과목 이상을 묶은 **교과융합 탐구보고서 과제**를 본사가 만들어 주고, 학생은 정해진 칸에 써서 **같은 포맷**의 보고서를 낸다.

가장 큰 염려(대표): 원장이 어려워서 못 쓰는 것. 원장 화면은 "고르기 → 배정 → 확인"으로 끝나야 한다.

## 2. 대표 결정

| 번호 | 결정 |
|---|---|
| Q-1 | 대상은 중학생까지(초·중). |
| Q-2 | 과제 = **주제(질문형 제목 + 부제) + 탐구 문제 3개**가 한 세트. 주제에 서논술 키워드가 들어가지 않아도 된다(심화탐구보고서처럼). |
| Q-3 | 탐구 문제마다 그 문제를 쓰는 데 쓸 자료(논문·뉴스·도서)를 **발췌와 함께** 붙인다. |
| Q-4 | 과제 하나에 DBpia 논문 2편 이상 + 뉴스 기사 1건 이상 + 도서 1권 이상. |
| Q-5 | 도서는 북코스모스 요약본이 있는 책 우선, 그다음 네이버·구글 도서. **선정적인 내용의 도서는 절대 금지.** |
| Q-6 | 아무것도 지어내지 않는다 — 자료는 실제 페이지를 확인한 것만. 본사가 「확인함」을 표시한 자료만 게시된다. |
| Q-7 | 차례: Ⅰ 서론(탐구 동기·탐구 문제) → Ⅱ 이론적 배경 → Ⅲ 탐구 방법 → Ⅳ 탐구 결과 → Ⅴ 결론 → Ⅵ 배우고 느낀 점 → Ⅶ 참고문헌. 실험·설문이 없으면 Ⅲ은 **생략 가능**(기본값 생략), 체크박스·드롭다운으로 정한다. 생략하면 번호를 당긴다. |
| Q-8 | 학생은 차례대로 놓인 **칸**에 쓴다. 칸마다 길잡이 질문과 권장 분량. 탐구 결과 칸은 탐구 문제 가·나·다 순서 그대로 셋. |
| Q-9 | 희망 진로는 빈칸 — 학생이 직접 쓴다(칸 자체는 원장이 체크로 넣고 뺀다). |
| Q-10 | 서논술 대주제와 연결한다(과제는 대주제에 붙을 수 있다 — 선택). |
| Q-11 | 첫 과제: 세트 2 「규제는 사람의 생각을 바꾸는가, 행동만 바꾸는가 — 일회용 컵 정책의 변화 과정을 중심으로」(사회 + 국어). |

## 3. 1차 범위(설명회 전) — 가정, 대표가 바꿀 수 있음

- 본사: 과제 만들기·고치기·자료 확인 표시·게시
- 원장: 과제 고르기 → 학생 배정 → 목차 확인 → 작성 현황 → 보고서 보기·인쇄
- 학생: 칸에 쓰기(자동 저장) → 제출 → 자기 보고서 보기
- 뒤로 미룸: 화면 첨삭, AI 도움말·피드백, 과제 자동 생성, 사진·표 첨부

## 4. 자료(과제) 모양

`InquiryTask`
- `title`, `subtitle`, `subjects`(2개 이상, 제작소 과목 다섯 중), `level`(초/중), `theme_id`(선택)
- `questions`: 정확히 3개 `{ key: '가'|'나'|'다', text, lens }` — lens 는 "과목 A의 눈 / 과목 B의 눈 / 융합"
- `sources`: `{ id, kind: 'paper'|'news'|'book', title, authors, year, container(학술지·매체·출판사), detail(권호·쪽·날짜), url, note(학술대회 발표문 등), easy_summary(중학생용 2~3문장), excerpts: { text, locator }[], for_questions: ('가'|'나'|'다')[], verified: { by, at } | null }`
- `section_guides`: 칸마다 길잡이 질문·권장 분량(기본값은 content/site.ts, 과제가 덮어쓸 수 있음)
- `teacher_tips`: 지도할 때 짚을 점(한 줄에 하나)
- `status`: draft | published

게시 조건(막는 조건은 자료의 진위에 한정): 확인함 표시가 있는 논문 ≥ 2, 뉴스 ≥ 1, 도서 ≥ 1, 탐구 문제마다 확인된 자료 ≥ 1. 확인함이 없는 자료는 학생·원장에게 보이지 않는다.

발췌: 자료마다 2~3문장 이내, 출처를 바로 아래에 적는다. 발췌가 비어 있어도 게시는 된다(쉬운 요약과 링크만 보임).

## 5. 목차(원장)

`outline`: `{ method: 'none' | 'survey' | 'experiment' | 'data', career: boolean }` — 기본 `{ method: 'none', career: true }`.
원장이 바꾸지 않으면 [확인]만 누른다. 학생이 쓰기 시작한 뒤 목차를 바꾸면 쓴 글은 지우지 않고 숨긴다.

## 6. 학생 쓰기

칸(세로 순서): 희망 진로(선택) → 탐구 동기 → 탐구 문제(3개, 미리 채움·고칠 수 있음) → 이론적 배경 → (탐구 방법) → 탐구 결과 가·나·다 → 결론(요약·한계·제안) → 배우고 느낀 점 → 참고문헌(읽은 자료 체크 → 자동 작성).
탐구 결과 칸 옆(아래)에 그 문제에 붙은 자료의 쉬운 요약·발췌·링크를 보여 준다. 자동 저장. [제출] 뒤에는 읽기 전용, 원장이 [다시 쓰게 하기]로 연다.

## 7. 인쇄 포맷

표지(제목·부제·학년 반 번호 이름·융합 과목) → 차례 → 본문(로마 숫자 장) → 참고문헌. 모든 학생이 같은 모양. 대표가 포맷 파일을 주면 그에 맞춘다.

## 8. 권한

본사: 전체. 원장: 게시된 과제 읽기, 자기 가맹원 학생의 배정·보고서. 학생: 자기 배정·보고서만, 제출 전까지 쓰기.
