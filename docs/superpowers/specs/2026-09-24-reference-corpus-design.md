# 교육청 공개 자료를 제작 파이프라인의 근거로 쓰는 설계 (순서도)

작성 2026-09-24 · 대상 자료: `바탕 화면/다빈치서논술참고자료`(4개 폴더, 178개 PDF, 36,528쪽) + `바탕 화면/다빈치 서논술 자료`(서울시교육청 11권 등, 약 4,600쪽) + 「[개념완성] 수학 중1-1학기」(시중 문제집 28개 파일)

이 문서는 대표님이 읽으실 수 있게 썼습니다. "어떤 자료에서 무엇을 가져와 제작 단계의 어디에 쓰는가"를 순서도와 표로 정리하고, 일정과 우선순위를 제안합니다.

---

## 0. 한 장 요약

지금 제작소는 **AI의 일반 지식 + 우리가 쓴 규칙 몇 줄**로 문항을 만듭니다. 이 자료들을 쓰면 다음 넷이 **교육청 공식 자료 기준**으로 바뀝니다.

| 제작 단계 | 지금 | 자료 반영 후 |
|---|---|---|
| 재구성·차시 설계 | AI가 형식을 스스로 정함 | 교육부 「교육과정 재구성 예시 자료집」의 성취기준 묶음·차시 배열 형식 그대로 |
| 수준(레벨) | 등급표를 AI가 지어냄 | 평가원 「2022 성취수준」의 성취기준별 **A/B/C(중)·A~E(고)·상중하(초) 수준 설명**을 DB에 넣고, 채점표·등급표·피드백이 그 수준 문장을 씀 |
| 서·논술형 문항 | 규칙 + 샘플 1세트 | 과목별 가이드북·평가도구 자료집·수행평가 자료집의 **실제 문항·조건·채점 기준을 예시 은행**으로 넣고, 생성할 때 같은 과목·학년의 예시를 함께 보여 줌 |
| 루브릭·피드백 | MYP 4요소 틀 | 공식 채점 기준 형식(평가 요소 × 척도 × 수행 특성, 채점 시 유의점, 단계별 예시 답안)으로 통일 |
| 세특(새 단계) | 없음 | 「학교생활기록부 기재 예시」의 "채점 기준 → 세특 문장 도출" 방식으로, 학생별 확정 채점·퀴즈·재도전 결과에서 **세특 문장 초안** 생성 |

자료는 교육부·평가원·시도교육청이 공개한 것이라 형식·문항·채점 기준을 그대로 써도 됩니다. 시중 문제집(「개념완성」)만은 **난이도 대조용**으로 쓰고 문장을 옮기지 않습니다.

## 3. 지식 베이스의 모양 (코드가 읽는 형태)

| 이름 | 형태 | 내용 |
|---|---|---|
| `standards` | DB 표(있음) | 성취기준 코드·원문·검증 여부 |
| `standard_levels` | DB 표(새로) | 성취기준 코드, 수준(A/B/C, A~E, 상/중/하), 수준 설명 문장, 출처(문서·쪽) |
| `data/exemplars/<과목>/<학교급>/*.json` | 파일 | 문항 본문, 조건, 배점, 채점 기준(요소×척도×수행특성), 예시 답안, 채점 유의점, 출처. 태그: 과목·학년·단원·유형(서술/논술/수행) |
| `lib/studio/prompts/rules/<과목>.ts` | 지시문 규칙 | 공통 규칙 + 과목별 규칙(가이드북·톺아보기·개념완성 대조에서 추출) |
| `data/templates/*.json` | 서식 | 재구성 표, 차시 배열 표, 채점 기준표, 세특 문장 틀 |

제작 단계는 세트를 만들 때 **같은 과목·학교급·가까운 단원의 예시 3~5개**를 골라 AI에게 함께 보여 줍니다(예시 은행에서 자동 선택). 성취수준 문장은 2·5·7단계에 그대로 들어갑니다.

## 4. 처리 순서 (일정 제안)

발표(10/18)까지 3주 남았고 3주차-B(사진·교재·공유 자료), 4주차(홈페이지·리허설)가 잡혀 있습니다. 그래서 **발표 전에는 "중학교 수학·과학 + 세특 1단계"까지**, 나머지는 발표 뒤로 나눕니다.

### 발표 전 (약 6일, 3B와 번갈아 진행)

| 단계 | 할 일 | 자료 | 산출물 | 소요 |
|---|---|---|---|---|
| A. 추출 | 178+11권 전체 글자 추출(자동), 이미지 전용 1,435쪽은 목록만 | 전부 | 로컬 말뭉치(저장소 밖) + 목차 색인 | 0.5일(자동) |
| B. 성취수준 DB | 중등 국·수·사·과·영·역사·도덕 + 초등 3권 → `standard_levels` | 2.1 | 마이그레이션 + 추출 스크립트 + 대조 시험(성취기준 코드 1,814개와 연결률) | 1.5일 |

## 5. 주의할 점

- **수식이 빠지는 문제**: 수학 PDF는 글자 추출 시 수식·숫자가 비는 경우가 있습니다(예: 성취수준(수학) p.57의 계산식). 수학 예시는 해당 쪽을 **그림으로 렌더링해 읽는** 보완이 필요합니다(pymupdf로 가능).
- **저작권**: 교육부·평가원·교육청 자료는 공공누리 조건(출처 표시)으로 씁니다. 예시 은행 항목마다 출처(문서·쪽)를 남기고, 원장 화면·교재에 실릴 때는 출처 표기를 붙입니다. 「개념완성」은 패턴만.
- **세특의 성격**: 학원은 학교생활기록부를 쓰지 못합니다. 7단계 산출물은 "학생 활동·성장 기록(세특 형식)"으로, 학생·학부모 안내와 학교 제출용 참고 자료로 씁니다. 화면 문구도 "세특 문장 초안"이 아니라 "활동 기록"으로 합니다.
- **양**: 36,000쪽을 AI가 다 읽는 것이 아니라, 자동 추출로 색인을 만들고 **필요한 절만** 읽습니다. 예시 은행은 구조화 추출이라 쪽당 비용이 낮고, 규칙 추출은 총론·가이드북 위주라 적습니다.
