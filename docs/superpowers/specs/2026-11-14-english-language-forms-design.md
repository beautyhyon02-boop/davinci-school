# 영어 목표 언어 형식(문법)과 퀴즈의 사고 과정 — 설계 (대표 확인 2026-11-14 "진행해, 단원 평가에도 반영해줘")

날짜: 2026-11-14 · 앞 문서: `2026-11-13-quiz-roles-design.md`

영어는 우리나라에서 문법을 안 가르칠 수가 없다. 각 대주제에서 문법을 2개 이상 가르쳐야 한다. 배운 문법을 사용해 문장을 다양하게

## 2. 규칙 문장

### 2-1. 모든 과목

- **L-24 (덧붙임)**: 2·3번은 자료의 한 칸·한 문장을 그대로 옮기면 답이 되는 문항으로 내지 않는다 — 고르기(여럿 가운데 골라 쓴다)·
  견주기(두 곳 이상을 견준다)·바꾸기(꼴이나 읽는 사람을 바꿔 다시 쓴다)·잇기(두 사실, 또는 근거와 주장을 잇는다) 가운데 하나가 들어가야 한다.
- **L-10 (고침)**: 2번과 3번은 그 차시가 길러 주는 단원 평가 채점 요소(lesson_map의 criteria_focus) 가운데 하나의 이름을
  criteria_ref에 적는다(요소가 둘이면 나누어 맡고, 하나면 둘 다 그 요소).

### 2-2. 영어

- **S-영-11 (신설) 목표 언어 형식**: 영어 세트는 대주제의 쓰기 과제에 실제로 쓰이는 목표 언어 형식(문법)을 2~3개 정해 가르친다.
  2단계에서 후보를 3~4개 낸다 — 후보마다 이름(한국어), 꼴, 대주제 맥락의 영어 예문 하나, 이 대주제의 글에서 하는 일, 고른 근거를 적고
  권하는 순서대로 놓는다. 본사가 2~3개를 고르고(고르지 않으면 앞의 두 개), 고른 것만 3단계로 넘어간다.
- **S-영-12 (신설) 차시**: 고른 언어 형식마다 처음 가르치는 차시를 정해 lesson_map의 language_focus에 적는다(한 차시에 새 형식은 하나).
  그 차시의 전개에서 꼴·뜻·쓰임을 자료의 문장으로 보여 주고, 활동지에 그 형식으로 문장을 쓰는 연습을 넣는다.
  뒤 차시의 활동지·퀴즈에서 앞에서 배운 형식을 다시 쓰게 한다. 문법 용어의 이름·정의를 묻지 않는다.
- **S-영-10 (고침) 퀴즈**: 영어 퀴즈는 세 문항 모두 영어로 답한다(지시문·조건은 한국어, S-영-04).
  1번은 그 차시에 배운 언어 형식의 꼴이나 표현을 낱말·짧은 구로 쓴다(용어 이름을 묻지 않는다).
  2번은 배운 언어 형식을 써서 자료에서 스스로 고른 내용을 영어 한 문장으로 쓴다(두 항목을 골라 견주기, 수치를 골라 근거로 삼기).
  3번은 같은 뜻을 다른 꼴로 바꿔 쓰거나 두 문장을 이어 쓴다(읽는 사람을 바꿔 다시 쓰기, 근거와 요청 잇기) — 단원 평가의 글에 들어갈 문장이 되게 한다.
  2·3번의 조건에는 써야 할 언어 형식의 이름을 밝히되(language_form) 정답이 되는 낱말은 적지 않는다(S-영-05).
  목표 형식을 썼으나 꼴에 잘못이 있는 답은 부분, 목표 형식을 쓰지 않은 답은 틀림이다.
  표의 한 칸을 문장으로 옮기기만 하는 문항과 한국어로 까닭을 설명하게 하는 문항은 내지 않는다.
- **S-영-05 (덧붙임)**: 세트의 목표 언어 형식은 조건에 이름으로 밝힐 수 있다(S-영-11) — 그 밖의 문법 조건은 그대로 금지.
- **S-영-13 (신설) 지침서**: 교사용 지침서에 목표 언어 형식마다 꼴·뜻·학생이 자주 틀리는 모습을 한국어로 적는다(비전공 원장용, 학생 비공개).

## 3. 화면·자료 구조

- 2단계(재구성·목표·핵심질문) 출력에 `language_form_candidates`(영어 세트만, 3~4개: name·form·example·use·basis).
- 2단계 화면에 「목표 문법 고르기」 칸 — 후보를 체크해 2~3개 고른다. 앞의 둘이 미리 골라져 있고, 고르지 않아도 [확인]으로 진행된다(막지 않음).
  고른 것은 2단계 출력의 `language_forms`에 저장(새 DB 칸 없음 — 마이그레이션 없음).
- 3단계: `lessons[].language_focus`(선택 — 구현하며 차시 구성표가 아니라 차시 자체에 두었다: 차시 카드·6단계 입력이 차시를 읽는다), 퀴즈 `language_form`(선택, 2·3번), 2번에도 `criteria_ref`.
- [TS] 참고 메모(막지 않음): 고른 형식이 어느 차시에도 없음 / 영어 2·3번에 language_form 없음·고른 형식이 아님 / 2번 criteria_ref 없음.
- AI 뜻 판정에 "써야 하는 언어 형식" 한 줄과 **그 차시가 쓰는 자료의 글**을 보낸다(새 규칙 판의 2·3번만) — 학생이 자료에서 스스로 골라 쓰면 정답이 여러 가지라 정답 표기는 예시이고, 사실 여부는 자료로 가린다(`quizMaterialsText`, 4,000자 상한).
- 6단계 지침서에 목표 언어 형식 설명 칸.

## 4. 정한 것·남은 것

1. 단원 평가(서술형·논술형)에도 반영한다(대표 2026-11-14) — "언어 사용" 채점 요소가 목표 언어 형식을 바르게 썼는지를 본다(조건으로 강제하지는 않음, S-영-14).
2. 학년 범위의 기준 — 가진 교과서 목차(비상)는 영어가 주제 단원이라 문법이 학년별로 나오지 않는다. 교육과정의 언어 형식 표나
   대표가 쓰는 교재의 학년별 문법 표가 있으면 후보의 근거로 넣는다. 없으면 본사가 고를 때 걸러 낸다.

## 5. 이미 만든 세트

영어 두 세트(일회용품·도서관)는 2단계부터 다시 생성해야 한다(새 판 게시 필요, 배정 자동 전환 없음).
일회용품 영어는 3단계가 생성됨(확인 전)·4~7단계 준비 전 상태 — 규칙 반영 뒤 2단계부터 다시 만든다.
다른 과목은 L-24·L-10 고침이 3단계를 다시 생성할 때 적용된다.

## 6. 범위 밖

- 퀴즈 3문항·단답형만·객관식 금지는 그대로. 문법 용어 이름을 묻는 문항은 내지 않는다.

## 7. 독립 검토 반영 (2026-11-14, 커밋 f740c4f 뒤)

- AI 뜻 판정: "정답 표기는 예시"는 문항이 "골라"라고 말하는 열린 문항에만(`isOpenChoiceQuiz`) — 그런 문항에만 자료를 보내고 이름표를 "정답 표기(예시 …)"로 바꾼다.
  값·항목 하나를 묻는 닫힌 문항은 정답 표기가 기준. 형식을 쓰지 않은 답은 뜻이 같아도·답 조건에 적혀 있어도 틀림. 써야 하는 형식은 영어 세트의 2·3번에만 보낸다.
- 3단계 과제: 학생이 자료에서 스스로 고르게 하는 문항은 문항에 "골라"라고 분명히 쓴다(판정이 이 말로 열린 문항을 알아본다).
- 후보가 없는 옛 영어 세트의 3·5·6단계: "목표 언어 형식을 정하지 않았다 — language_focus·language_form·language_forms를 두지 않는다".
- 생성 직후 손질(`lib/studio/language-forms.ts`): 형식 검사 전 `repairLanguageKeys`(2단계 language_forms 삭제·null 칸 삭제), 검사 뒤 `scrubLanguageForms`
  (영어가 아닌 세트·형식 없는 영어 세트의 새 칸 삭제). 후보 개수 하한은 두지 않는다.
- 고르기 칸: 단계가 도는 동안 잠금, 다시 생성하면 체크를 새로 잡음. 고른 이름이 하나만 남으면 앞의 후보로 두 개까지 채움.
- 규칙 문장: L-24(네 가지는 예시 — 식 세우기·규칙으로 예측하기도 같다), S-영-05(형식의 이름은 퀴즈의 답 조건에만), S-영-10(적지 않는 것은 정답 문장의 내용),
  S-영-11(그 학교급 학년군). 4단계 자료에 목표 형식을 쓴 문장을 형식마다 하나 이상.
- 남긴 것: 문장 고치기로는 빠진 language_form·language_focus 를 새로 적을 수 없다(JSON 편집뿐). JSON 편집을 열어 둔 채 문법을 고르고 JSON 을 저장하면 선택이 지워진다.
