# 문항 제작소 v2 — 대표님용 요약

작성 2026-09-25 · 상세 설계: `2026-09-25-item-studio-v2-design.md`

어제까지 교육부·평가원·시도교육청 공식 자료 약 5만 쪽을 읽어 연구 문서 7편, 성취수준 데이터(966개 성취기준), 예시 문항 은행(531건), 서식 2종을 만들었습니다. 이 요약은 그것을 제작소에 어떻게 넣을지, 원장님과 학생에게 무엇이 달라지는지, 5일차에 무엇을 봐 주셔야 하는지를 정리한 것입니다.

---

## 1. 한마디로

지금 제작소는 "AI의 일반 지식 + 우리가 쓴 규칙 몇 줄"로 세트를 만듭니다. v2는 **공식 자료의 서식과 원칙을 뼈대로 쓰고**, 공식 자료가 다루지 않는 학원 상황(60분 수업, 비전공 원장님, 5과목 공유 대주제, 학부모 안내장, AI 채점)은 근거를 밝히며 우리가 채웁니다. 대표님이 이미 정하신 것(5과목 공유 대주제, 4~6차시×60분, 퀴즈 3문항, 서술형 2+논술형 1=22점, 7등급, AI 초안→원장 확정, 재도전 1회, 표·그래프는 종이 답안)은 그대로입니다.

---

## 2. 원장님에게 달라지는 것

| 지금 | v2 |
|---|---|
| 차시마다 "도입·전개·정리" 문장 세 줄 | **60분 지도안**: 도입 10분·전개 40분(소단계마다 몇 분)·정리 10분, **읽어 줄 발문 2~4개와 예상 답, 학생이 막힐 때 줄 힌트**, 준비물, 주의할 오개념. 2시간 등원 반은 "두 차시를 합칠 때 빼도 되는 활동"까지 표시 |
| 활동지 없음 | 차시마다 **활동지**(기본·표준·도전 과제 + 학생 자기평가). 첫 주는 한 장에 세 과제, 수준별 세 장 분화는 발표 뒤 |
| 문항: 문두·조건·채점표 | **문항 카드**(경기도교육청 2025 서식): 평가 요소, 과제 상황(누가·누구에게·왜·무엇을), 자료, 문두, **조건마다 "무엇을 하면 몇 점"**, 채점표(요소×점수 단계, 1점 단위, 조건과 1:1), 논술형은 상/중/하 총평, **점수 단계마다 예시답안**, 채점할 때 주의점(표현이 달라도 인정하는 범위 등), 성취수준 A~E별 예상 점수 |
| 지침서에 발문·주의점·퀴즈 해설이 따로 | 그 내용은 지도안으로 들어가고, 지침서에는 세트 준비물·일정, 용어, 병합 안내, **AI 채점 검수 요령**(흔한 오답, 재도전 안내)만 남음 |
| 없음 | **차시별 안내장**: 수업 뒤 학생·학부모에게 보내는 한 장(오늘 배운 것, 퀴즈 결과, 확정된 서·논술형 점수와 요소별 잘한 점·보완할 점, 재도전 향상, 다음 차시, 가정 학습 제안, 원장 한마디). 하단에 "학교생활기록부가 아닌 학원 학습 기록" 고지. 확정된 채점만 실림 |
| 자료는 전부 자작 | 자작 자료 + **공개 자료(출처 표기)**도 허용. AI가 만든 자료는 "확인 필요" 표시 |

원장님이 볼 화면과 교재에는 성취기준마다 **A~E 수준 문장**(평가원 자료 원문)이 접혀서 붙고, 문항 카드 끝에 **참고한 공개 자료 목록**이 표기됩니다.

## 3. 학생에게 달라지는 것

- 차시 화면에 **활동지**가 보이고, 퀴즈 3문항은 지금처럼 즉시 채점.
- 문항은 조건이 **번호 매긴 표**로 보여서 무엇을 쓰면 몇 점인지 알 수 있습니다.
- 표·그래프를 그리는 문항(세트당 최대 1개)은 "종이에 풀어 선생님께 내세요"로 안내, 나머지는 화면 입력.
- 결과 화면은 지금과 같지만(원장 확정 후 공개, 요소별 점수·근거·잘한 점·보완할 점), 그 뒤 **안내장**을 받습니다.

## 4. 5과목 세트는 이런 모양으로 나옵니다

공통 뼈대: 표지 → 대주제 소개 → 성취기준 원문(+A~E 수준) → **재구조화 표**(성취기준마다 통합/재조정/유지, 원문 병기) → 학습 목표(지식·이해/과정·기능/가치·태도 표시) → 핵심질문 → 평가 계획표 → 차시 지도안 4~6장(활동지·퀴즈 포함) → 자료(출처) → 문항 카드 3장 → 등급표 → 피드백 틀 → 안내장 틀 → 참고 자료.

과목별 색깔(공식 자료의 관행을 따름):

| 과목 | 문항 특징 | 자료 |
|---|---|---|
| 국어 | 두 자료 (가)(나) 비교·관점 파악, 논술형은 서론-본론-결론+근거+인용 표기 | 글 2편(중1은 각 200~400자) |
| 수학 | 표·그래프를 읽고 계산·비교·판단; 표를 새로 만드는 문항은 1개만(종이); 논술형은 두 자료 종합해 목표 수치 정하고 근거 | 표 5~10행, 원자료 20~25개 |
| 사회 | 자료 해석+원인·영향, 논술형은 입장+근거(입장이 아니라 근거를 채점) | 통계·지도·기사, 실제 자료 우선 |
| 과학 | 실험 자료·그래프 해석, 변인 구분, 필수 용어 조건; 논술형은 쟁점 찬반 모두 고려 후 입장 | 표·그래프·도식 |
| 영어 | 지문·표를 읽고 영어로 쓰기, 분량은 단어 수, 채점은 내용/구성/언어사용 | 영어 지문·인포그래픽 |
| 역사(여유 시) | 상반된 1차 사료 2개 이상, 인용 조건 | 사료·지도 |

## 5. 일정

- **3~4일(필수)**: 새 형식(스키마)·규칙 정리·성취수준·예시 은행 연결·문항 카드·안내장 틀·화면 대응 → 5과목 실제 생성·게시. 약 4일.
- **발표 뒤**: 성취수준·예시 은행을 DB로, 안내장 발송·열람 화면, 활동지 수준별 세 장, 초등·고등 분기, 역사 세트, 난이도 실측 보정, 복붙·외부 AI 탐지.

## 6. 5일차에 봐 주실 것 (과목당 25분, 약 2시간)

패키지 화면을 위에서 아래로 보시면서 12개 항목에 O/△/X를 적어 주세요.

1. 성취기준 원문이 그대로이고 재구조화 표에 원문이 나란히 있다
2. 학습 목표에 지식·과정·태도 세 축이 다 있고 "~할 수 있다"로 끝난다
3. 핵심질문이 "뜻이 무엇인가"식 사실 확인이 아니다
4. 차시 흐름을 보고 "이 대본이면 60분을 진행할 수 있겠다"
5. 발문의 예상 답과 힌트가 자연스럽다
6. 활동지 기본/표준/도전이 실제로 난이도 차이가 난다
7. 자료가 답을 미리 담지 않고, 표가 한 화면에 들어온다
8. 문항 조건만 읽어도 학생이 무엇을 쓸지 알 수 있고 배점이 조건 옆에 있다
9. 채점표 단계가 "정확하게/대체로"처럼 부사만 바뀐 것이 아니다
10. 논술형 예시답안 상/중/하를 직접 채점해 보면 적힌 점수가 나온다
11. 채점 주의점이 실제로 애매한 경우(반올림, 다른 표현)를 다룬다
12. 안내장 문장이 학부모에게 보내도 될 톤이다

X가 나온 항목은 그 단계만 다시 생성합니다(전체 재생성 없음). "설명회용으로 충분"의 기준: 5과목 게시, 자동 검사 전부 통과, 과목당 X 2개 이하, 자리 채움 문장 0건.

## 7. 대표님께 여쭐 결정 3가지

1. **활동지 형태** — 첫 주는 "한 장에 기본·표준·도전 과제"로 갑니다. 발표에서 "수준별 세 장"을 보여 주고 싶으시면 3~4일 안에는 어렵고 발표 직전 주에 넣어야 합니다. 어느 쪽인지.
2. **안내장 발송 범위** — 매 차시마다(퀴즈만 있는 차시 포함) 보낼지, 서·논술형이 있는 차시(3회)만 보낼지. 그리고 학부모에게 인쇄물로 줄지 링크로 줄지(발송 화면은 발표 뒤이므로 첫 주는 원장 화면에서 보고 인쇄).
3. **공개 자료 사용** — 사회·과학은 공식 자료가 실제 통계·기사를 선호합니다. 첫 5세트부터 출처를 표기한 공개 자료를 섞을지, 발표까지는 지금처럼 전부 자작으로 갈지(자작이 안전하고 빠르며, 공개 자료는 출처 확인 시간이 듭니다).

참고로 이번 설계에서 제가 정한 큰 결정은 다섯 가지입니다: ① 서술형 채점표를 "조건마다 몇 점" 1점 단위로 바꾸고 논술형 4요소×0~4는 유지 ② 예시답안을 문항마다 점수 단계별로(2025 경기도의 "1개"보다 많이) ③ 성취수준 A~E와 우리 7등급의 대응을 참조열로 병기(등급 체계 자체는 그대로) ④ 지침서를 지도안에 흡수하고 안내장을 7단계로 신설 ⑤ 기존 게시본은 다시 만들지 않고 읽을 때 새 모양으로 올림. 모두 상세 설계에 근거를 적어 두었습니다.
