# 단원 리포트(학생별·과목 통합) 설계

- 결정일: 2026-09-29 (대표 동의)
- 시한: 설명회 2026-10-18 시연에 포함
- 관련: `docs/superpowers/specs/2026-09-25-item-studio-v2-design.md`(제작소 v2), `docs/STATUS.md`

## 1. 목적

세트(단원)가 끝나면 학생 한 명에게 **그 단원에서 수업한 과목을 모두 합친 리포트 한 부**를 낸다.
원장은 퀴즈 O/X 와 평가 문항 점수만 확인하고, 코멘트는 이미 만들어 둔 문구(7단계 안내장 틀)에서 조합한다.

## 2. 대표 결정

| 번호 | 결정 |
|---|---|
| R-1 | 육각형 축은 과목과 무관한 공통 역량 6개: 지식·이해 / 자료 읽기 / 근거 들어 설명하기 / 글로 표현하기 / 과정·기능 / 가치·태도 |
| R-2 | 퀴즈 O/X 는 종이로 풀든 화면에서 풀든 **원장이 수업 뒤 최종 확인**한다 |
| R-3 | 리포트는 달력 기준이 아니라 **세트(단원)가 끝날 때** 낸다. 묶는 기준은 대주제 하나 + 학생 한 명 |
| R-4 | 학생에게 배정된 과목만 들어간다(영·수만 수업하면 2과목). 인쇄 전에 넣을 과목을 체크로 고를 수 있다 |
| R-5 | 서술형·논술형을 종이로 쓴 학생은 원장이 루브릭을 보며 **요소별 점수를 직접 입력**한다(사진 업로드·판독은 설명회 뒤) |
| R-6 | 기존 차시별 안내장은 그대로 두고 단원 리포트를 추가한다 |
| R-7 | 다른 학생과의 비교·등수는 넣지 않는다(안내장 규칙과 같다) |
| R-8 | 코멘트는 문구 조합 — 리포트를 만들 때 AI 를 부르지 않는다. 원장이 인쇄 전에 문장을 고칠 수 있다 |

## 3. 역량 꼬리표(6축)

- 상수 `COMPETENCIES`(6개, 위 순서)를 `lib/studio/schemas.ts` 에 둔다.
- `QuizItem.competency`, `Criterion.competency` — 선택 필드(옛 판·기존 세트와 호환).
- 3단계(퀴즈)·5단계(채점 요소) 생성 지시에 "문항·요소마다 역량 하나"를 넣는다. 본사는 문장 고치기/JSON 편집으로 바꿀 수 있다.
- 꼬리표가 없으면 읽을 때 채운다(`competencyOf`): 채점 요소는 `axis` 와 같은 이름의 역량, 퀴즈는 `지식·이해`.
- 기존 3차원 `axis`(지식·이해/과정·기능/가치·태도)는 그대로 둔다 — 학습목표·루브릭 규칙이 쓴다.

## 4. 원장 입력

### 4.1 퀴즈 최종 확인
- O/X 표(QuizMatrix)에서 응답이 없는 칸(종이로 푼 학생)도 원장이 O/X 를 넣을 수 있다(`quiz_responses.source = 'teacher'`).
- 차시마다 [최종 확인] — `quiz_finalizations(assignment_id, lesson_no, finalized_by, finalized_at)`.
- 최종 확인한 차시만 리포트에 들어간다. 확인 뒤 O/X 를 바꾸면 확인이 풀린다.

### 4.2 종이 답안 점수 입력
- 답안이 없는 평가 문항에 [종이 답안 점수 입력] — 루브릭(요소·척도)을 보여 주고 요소별 0..max 를 고른다.
- 저장: `answers`(source 'teacher', 본문은 종이 답안 표지) + `gradings`(status 'confirmed', model 'manual', final_criteria). AI 호출 없음.
- 이후는 화면 답안과 같다(세트 총점·등급·안내장·리포트).

## 5. 리포트

### 5.1 자료 모으기(순수 함수 `buildUnitReport`)
입력: 학생, 대주제, 과목별 {게시 판 스냅숏, 최종 확인된 퀴즈 응답, 확정된 채점}.
출력(`UnitReportBody`):
- `subjects[]`: 과목, 핵심질문, 퀴즈(차시·번호·정오·틀렸을 때 코멘트), 평가 문항(종류·요소별 점수·잘한 점·보완할 점), 과목 한 줄 요약, 빠진 것(미확인 차시·미채점 문항)
- `radar[6]`: 역량, 얻은 점수, 만점, 문항 수
- `overall_comment`: 가장 높은 축과 가장 낮은 축으로 조합한 문장
- `footer_disclaimer`: 안내장과 같은 문구

### 5.2 계산
- 축 점수 = 얻은 점수 합 ÷ 만점 합. 퀴즈 1문항 = 1점, 채점 요소 = 그 요소의 max.
- 문항 수가 2개 미만인 축은 `sparse`(흐리게 + "문항 수 적음").
- 자료가 하나도 없는 축은 비운다(0점으로 그리지 않는다).

### 5.3 코멘트 고르기
- 채점 요소: 점수 비율이 높으면 `criteria_phrases.good`, 낮으면 `improve` 에서 고른다. 같은 학생·같은 요소는 늘 같은 문구(결정적).
- 퀴즈: 틀린 문항만 `quiz_notes.wrong_note`.
- 문구가 없는 옛 세트는 점수만 보인다.

### 5.4 화면·인쇄
- `/teacher/reports` — 대주제별 학생 목록, 준비 상태(퀴즈 확인·채점 확정 개수)
- `/teacher/reports/[themeId]/[studentId]` — 과목 체크, 미리보기, 문장 고치기, [확정], [인쇄]
- 앞면: 학생·단원, 오렌지색 육각형, 과목별 한 줄 요약, 종합 코멘트 / 뒷면: 과목별 상세
- 육각형은 손으로 쓴 SVG(`components/classroom/RadarChart.tsx`), 차트 라이브러리 없음.
- 저장: `unit_reports(student_id, theme_id, academy_id, subjects, body, status, …)` — 확정본을 남긴다.

### 5.5 역량 뜻 표·종합 코멘트 줄(대표 요청 2026-09-30)
- 앞면 육각형 바로 아래에 표 「역량은 이렇게 봅니다」: 역량(굵게) | 뜻(학부모가 읽는 한 문장) | 점수. 뜻은 화면 문구(`app.classroom.report.view.meanings`) — 생성 지시용 `COMPETENCY_MEANING` 과 따로 둔다.
- 종합 코멘트는 줄마다 쓴다(`overall_lines`, 한 줄에 하나·이름표는 윗줄): 수업 태도 → 잘한 점 → 더 연습할 점 → 과목 한마디. `overall_comment` 는 줄을 이은 글로 남긴다.
- 수업 태도: 원장이 낱말만 고른다(참여 1 · 수업 모습 1~2 · 마무리 1). 본문에는 열쇠(`attitude`)로 저장하고 문장은 서버가 화면 문구로 만든다. 셋을 모두 골라야 줄이 생기고, 고르지 않아도 저장·확정·인쇄를 막지 않는다. 서버는 허용 목록 밖의 열쇠·수업 모습 3개 이상을 받지 않는다.
- 잘한 점·더 연습할 점: 가장 높은/낮은 축(§5.2 규칙) + 근거(그 축에서 비율이 가장 높은/낮은 채점 요소 — 과목·문항 종류·요소 이름·점수, 요소가 없는 축은 과목의 퀴즈 문항 수·정답 수). 더 연습할 점의 다음 할 일은 그 요소의 `improve` 문구 → 그 차시의 `home_study_suggestion` → 일반 문장 순.
- 과목 한마디: 이 학생의 과목 가운데 기록이 가장 좋은 과목과(둘 이상이면) 다음에 힘을 실을 과목. 다른 학생과 견주지 않는다(R-7).
- 높고 낮음을 가를 수 없으면 「잘한 점」 자리에 고른/중립 문장 한 줄 — 만든 줄은 늘 2개 이상(수업 태도까지 3줄 이상).
- 고친 문장의 열쇠는 자리 + 가리키는 것(역량·과목·요소, 수업 태도는 고른 낱말). [점수 다시 불러오기] 뒤에는 같은 것을 가리키는 줄에만 다시 덮는다. 낱말 고르기는 숫자 변경이 아니다(`reportDataKey` 에 들어가지 않는다).
- 새 칸(`attitude`·`overall_lines`·요소의 `improve_tip`·과목의 `home_study`)은 모두 선택 칸 — 그 전에 저장한 본문도 그대로 읽히고 한 문장짜리 코멘트로 보인다.

## 6. 권한
- 원장: 자기 가맹원 학생만. 본사: 전체. 학생·학부모 열람은 이번 범위 밖(원장 인쇄만).

## 7. 범위 밖
- 월간(달력) 리포트, 학부모 발송, 사진 업로드·판독, 단원 간 추이 그래프.

## 8. 작업 순서
1. 역량 꼬리표(스키마·프롬프트·보정·표시)
2. 마이그레이션 0014 + 퀴즈 최종 확인 + 종이 O/X 입력
3. 종이 답안 점수 입력
4. 리포트 계산(순수 함수)·육각형 SVG
5. 리포트 화면·확정·인쇄
6. 시연 자료·문서
