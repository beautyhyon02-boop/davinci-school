## 1. 이 자료집의 틀 — 우리 2·3단계와 어디가 겹치는가

**배경.** 2021학년도 원격수업 전환·등교-원격 병행에 대비해 2015 개정 성취기준을 **통합·재조정·유지** 세 유형으로 재구조화하고, 확보한 시간을 피드백·형성평가에 쓰라는 자료다(과학 p.9, 13). 줌·패들렛 같은 도구 이야기는 우리에게 쓸모가 없고, **재구조화 논리·차시 표·활동지·피드백 설계**만 본다.

**다섯 권 공통 구조.**
- Ⅰ 개요(p.9–20, 공통 본문): 재구조화 정의(교육부 훈령 발췌 — 통합·압축 시 내용요소 임의 삭제 금지, p.11), 유형 3개와 이유 태그(p.13), 수업 템플릿·평가 템플릿의 칸 설명(p.15–20).
- Ⅱ 성취기준 재구조화 예시: 내용체계표 → 재구조화 원칙과 방향(4단계) → 개관 표(성취기준 | 학습 요소 | 재구조화) → 영역·단원별 상세(표 + 〔재구조화 성취기준 해설〕 + 〔교수·학습 방법 및 유의사항〕 + 〔평가 방법 및 유의사항〕).
- Ⅲ 수업 예시: 머리 표(학년군·차시 구성 "n차시 → m차시"·기존 ⇨ 재구조화 성취기준·재구조화 이유 체크·주요 학습 요소·교과역량·해설) → ① 수업의 흐름(차시 | 단계 | 활동 | 수업 유형) → ② 교수·학습 계획(차시 | 단계 | 단계별 활동 | 도구) → ③ 세부 수업 진행(차시마다 수업 안내 · [유의사항] · 주요 학습 활동 화살표 · 평가 및 피드백 · 꿀팁) → ④ 수업 도구·학습 자료(활동지).
- Ⅳ 평가·기록 예시: ① 학생평가 운영 계획(재구조화 성취기준 + **평가기준 상/중/하** + 재구조화 이유 + **평가 요소 3~4개** + 교과역량 + **평가 의도**) → ② 교수·학습 및 평가 활동(차시 | 학습 목표 | 도입·전개·정리 | **평가 과제 + 피드백** | 평가 방법·주체·수행 방식) → ③ 학생평가 과제 및 피드백 방안(과제 표 → 활동지 → 운영 방안 → 피드백 제시 방안 → **학생 수준에 따른 과제 운영(상/중/하)** → 수행평가 채점기준표 + 채점 유의사항 → **성취수준별 피드백 예문**) → ④ 세특 기록.

**우리 산출물과의 대응.**
- Ⅱ(재구조화 개관·해설) ↔ 2단계 `standards[]`(유형·original_text·reconstructed_text·reason 태그·merged_with·learning_elements) + `reconstruction`.
- Ⅲ·Ⅳ의 차시 표 ↔ 3단계 `unit_plan.lesson_map` + `lessons[]`(flow·teacher_script·worksheet·quiz).
- Ⅳ의 평가 요소·채점기준표·피드백 ↔ 5단계 문항 카드와 7단계 안내장. 3단계에는 대응 칸이 없다(§3).

**이 자료의 한계(그대로 본뜨면 안 되는 것).**
- 2015 개정 코드다. 우리 DB는 2022 개정이라 코드가 같아도 내용이 다르다(2015 [9과01-01] = 지구계, 우리 fixture [9과01-01] = 과학적 탐구). 코드는 옮기지 않는다.
- 45분 수업·모둠 중심·원격 도구 전제. 우리는 60분·소규모·개인 답안이다.
- 채점표가 약하다: 3~4단계 척도의 차이가 "4가지/3가지/1~2가지"(과학 p.219) 또는 "~하기 위해 노력한다"(수학 p.175, 189)뿐인 곳이 많다 → 우리 C-25(부사만 다른 인접 척도 금지)가 더 엄격하다. 5단계 **부정 예시**로만 쓴다.
- 평가기준이 상/중/하 3단계다. 우리는 A~E 5단계(level_anchor)로 이미 더 세밀하다.

## 2. 과목별 관찰

### 2.1 과학(p.23–52, 131–142, 209–221)

**재구조화 논리(Ⅱ).**
- 4단계 절차: 성취기준마다 '핵심 학습요소와 탐구 활동' 키워드 추출 → 유사한 것을 지식·기능·태도로 분류해 묶는 방법 모색 → 하나의 문장으로 제시(중복 요소는 한 번만, 영역 목표와 일관되게) → 적합성 검토(p.33).
- 유형은 **통합·유지만** 쓴다(재조정 없음). 이유 태그: 통합 = 원격수업 전환 / 내용 요소 연계 / 기능 재조정 / 학습량 적정화, 유지 = 원격수업 가능 / 학습 결손 방지(p.33).
- 개관 표의 학습 요소를 **[지식]과 [활동]로 나눠** 적는다(p.34–46). 통합 코드는 `[9과01-02/01-04]`처럼 슬래시로 잇는다.
- 〔재구조화 성취기준 해설〕이 **어느 코드를 중심으로 묶었는지와 그 까닭**을 한두 문장으로 적는다. 예: 풍화 작용은 암석 순환 과정 안에서 설명할 수 있으므로 [9과01-02] 중심으로 통합(p.48). 유지 이유도 적는다: 네 가지 힘은 서로 다른 물리 개념이고 핵심 내용 요소의 연계성이 부족해 통합하지 않음(p.50).
- 단원별 표에 **[원격수업]/[등교수업] 활동 예시와 [평가] 문장("~을 설명할 수 있다")** 칸이 붙는다(p.47–52) — 성취기준 하나에 평가 진술 2~3개.
- 〔교수·학습 방법 및 유의사항〕에 안전·대체 활동, 〔평가 방법 및 유의사항〕에 "실시간 퀴즈로 평가 가능", "과정 평가와 결과물 평가 분리" 같은 운영 메모(p.49, 51–52).

**수업 예시 나 「상태 변화와 열에너지 관계 탐구」(p.131–142) — 통합 [9과05-03/05-04], 5차시 → 3차시.**
- 머리 표에 "5차시 → 3차시"가 명시되고, 해설이 통합의 중심 학습 요소(열에너지 출입)를 짚는다(p.131).
- 수업의 흐름: 1차시 개념 이해 + 자료 해석(어는점·끓는점 그래프), 2~3차시 입자 운동 시뮬레이션 관찰 → 열에너지 관계 모둠 논의 → 생활 사례 조사·발표(p.132–133).
- 세부 진행의 [유의사항]에 **과학의 본성 메모**: 실제 측정은 교과서 그림처럼 깨끗하게 일정 구간이 보이지 않으므로 "상대적으로 일정한 구간"을 찾게 한다(p.134). 우리 caution_notes(오개념)와 같은 결의 메모이되 한 단계 높다.
- 평가 및 피드백: 이 차시 이해가 다음 차시(열에너지 관계) 전제이므로 **다음 차시 전에 이해 여부를 확인하고 개별 피드백**(p.135); 개별 평가는 "내용의 옳고 그름보다 5개 사실을 충실히 관찰했는지"에 초점(p.137); 모둠원마다 문항 하나씩 책임 작성(p.137).
- 꿀팁: 교사가 **탐구 과정에 오류를 일부러 넣은 영상**을 찍고 학생이 오류를 찾게 한다(p.138) — 실험을 못 하는 상황에서 탐구력을 보완하는 장치.
- 〈활동지 1〉(p.140–141): 목표 → 준비물 → 개념 이해(교과서 보고 용어 4개 정의 적기) → 자료 해석(① 가열 그래프에서 알 수 있는 사실 3가지 → ② 일정한 구간이 있는가, 어디인가 → ③ 냉각 그래프 사실 3가지 → ④ 구간 → ⑤ 두 그래프 중 녹는점을 찾을 수 있는 것은 무엇이고 **왜 그렇게 생각했는지**). 정의 → 관찰 → 판단 → 선택+이유의 **인지 수준 진행**이 한 장 안에 있다.

**평가·기록 예시 다 「생물다양성」(p.209–221) — 통합 [9과03-01/03-03], 4차시.**
- 운영 계획: 평가기준 상/중/하(p.209; '하' 문장에 오탈자 "판단할 있다"), 평가 요소 3개("~하기"), 평가 의도.
- 차시 표(p.210–212): 차시마다 학습 목표·도입/전개/정리·**평가 과제([형성평가] 1~3, [수행평가] 4) + 피드백 방법**·평가 방법(구술/서술·교사/자기/동료·개별/조별).
- 과제 2(p.216–217): 토종 종자 인터뷰(출처 명시) 읽고 정보 4개 파악 → 지도에 품종·위치 표시(사회과 연계) → 영상 보고 질문 3개. 피드백은 "요약을 잘했는지" 중심, GMO는 중립적으로(p.217).
- 과제 3·4(p.218): 조사 → 스토리보드 → **1차 검토 도장 → 제작 → 2차 검토 도장 → 갤러리워크**. 과정은 O/X로만 평가하고 산출물은 채점표로(p.218–219). 채점 유의사항에 "자료에 들어갈 요소·가짓수를 명시하는 것도 좋다".
- 채점표(p.219)는 4-3-2-1이 가짓수 차이뿐 — 우리 기준으로는 약하다(§1 한계).

### 2.2 국어(p.23–34, 75–84, 116–134)

**재구조화 논리.**
- 운영 원칙 세 가지(p.23)와 평가 방향에 중요한 한 줄: 통합·재조정한 성취기준을 **"하나의 성취기준으로 교수·학습 및 평가하지 않도록" 유의하고, 학습자에게 무엇에 초점을 맞출지 미리 안내**(p.24). → 통합해도 원 성취기준의 요소를 각각 가르치고 평가한다는 뜻(우리 L-01 '내용요소 삭제 금지'와 같은 방향).
- 재구조화는 **학습 요소의 연계성** 중심(p.27). 영역을 가로지르는 통합이 많다: 듣말+읽기+쓰기 `[9국01-05/02-06/03-04]` "비교하며 읽고 → 토론 개요서 → 토론"(p.28), 읽기+쓰기+고쳐쓰기 `[9국02-04/03-02/03-09]`(p.29), 문학+매체 `[9국03-08/05-03]`(p.30).
- 재조정 = 기능 연계·압축(예: 설득 전략 분석 듣기 + 문제 해결 과정 쓰기 → 설득 전략을 활용한 글쓰기, p.28).
- 통합 예시 표(p.32–34)에 **'재구조화 이유' 칸이 문장**이다: 토의에서 합리적 해결을 하려면 타당한 근거로 의견을 냈는지 판단하며 듣는 활동이 전제이므로 통합(p.32); 담화 개념은 실제 국어생활로 배우는 것이 효과적이라 공감 대화와 묶음(p.34). 뒤에 【교수·학습 및 평가 유의 사항】 2~4줄.

**수업 예시 나 「관점이 다른 글 읽고, 토론하기」(p.75–84) — 통합 [9국02-06/01-05/03-04], 중3, 5차시.**
- 흐름: 1~2차시 토론 개념 + 관점 다른 글 비교 읽기·나의 생각 쓰기 → 3~4차시 논제·쟁점 정하기, 자료 찾아 찬반 근거 모두 마련, 토론 개요서 → 5차시 역할 토론·상호 평가(p.76–78).
- 세부 진행의 발문 예: '자율주행 자동차 전면 도입' 논제에서 편의·안전뿐 아니라 **운전의 즐거움·일자리·윤리적 딜레마**로 관점을 넓히는 발문을 교사가 던진다(p.80). 개요서는 상대편 예상 주장과 반론까지 담으므로 자료를 한쪽에 치우치지 않게(p.80).
- 평가 및 피드백: 토론 평가지를 **미리 나눠 주어** 인상 평가가 아니라 타당성·신뢰성·공정성으로 평가(p.76, 81).
- 수업의 팁(p.82): 통합의 **매개 요소**('관점의 차이', '주장과 근거의 타당성')를 먼저 찾고, 통합 요소의 공통점 중심으로 활동을 짜되 **차이점도 고려해 누락되는 성취기준이 없게**. 학습량 때문에 토론으로 끝냈지만 대안을 담은 정리 글쓰기로 이어갈 수도 있음.
- 활동지(p.83–84)는 패들렛 캡처(그렇다/아니다 두 열에 근거 붙이기) — 구조만 참고.

**평가·기록 예시 나 「설명 방법을 파악하며 글을 읽고 설명하는 글 쓰기」(p.116–133) — 통합 [9국02-04/03-02/03-09], 7차시.**
- 운영 계획(p.116): 평가기준 상/중/하가 '부분적으로/능동적으로'로 갈린다. 평가 요소 4개(설명 방법 파악 / 내용 수집·선정 / 개요·표현 / 독자 고려 고쳐쓰기). 평가 의도에 글쓰기 과정 단계마다 평가 요소를 하나씩 뽑았다고 적는다.
- 차시 표(p.117–118): 1~2차시 형성 1(설명 방법 파악), 3~4차시 형성 2(글쓰기 과정 익히기), 5~7차시 수행(모둠 글쓰기 → 다른 모둠 글 **개별** 평가 → 반영해 고쳐쓰기). 수업 의도에 "모둠으로 쓰고 평가는 개인이" 하는 까닭(중2가 혼자 쓰기엔 어렵다)을 적었다.
- 활동지 1(p.119–121): 문항마다 **♣ 활동 도움말**이 붙는다 — "자주 반복되는 단어는?", "개념이 풀이되는 단어는?", 설명 방법 6개를 **질문형**으로("둘 이상을 견주어 공통점·차이점을 밝히고 있나요?"). 답을 주지 않고 **찾는 절차**를 묻는 도움말이다.
- **교사 평가 결과지**(p.121): 평가 요소 5개마다 상/중/하 체크 + 피드백 한 단락 — "설명 방법 파악이 어려워 적절성 평가·효과 파악도 낮다 → 설명 방법이 잘 드러난 부분을 다시 보고 재도전" 같은 **진단 연쇄**.
- 활동지 2(p.122–125): 내용 선정(자료 (가)~(마) 중 **주제에 어긋나는 것 고르고 까닭**) → 개요 점검 → 설명 방법 고르기 → 밑줄 ㉠~㉣ 고쳐 쓰기(점검 항목 4수준: 글·문단·문장·단어). 운영 방안에 "교사는 통일성에 어긋난 부분을 자료에 포함"해 학생이 찾게 한다(p.125).
- **학생 수준에 따른 과제 운영 방안**(p.125): 상 = 논문·학술지 사이트에서 신뢰도 높은 자료 + 추가 수정 2곳 이상 찾기, 중 = 인터넷 자료 2개 이상, 하 = 통일성 있는/벗어난 예시 자료와 고쳐쓰기 예시를 함께 제시. **같은 과제, 다른 지원과 확장**.
- 수행 운영 방안(p.129): 평가 전에 채점기준표를 먼저 보여 주어 무엇에 유의할지 알게 하고, 모둠 수행 중 개별 수행을 병행해 무임승차를 줄인다.
- 성취수준별 피드백 예문(p.130)은 학생이 쓴 글의 소재까지 언급하는 **개인 맞춤 문단** 3개(상/중/하).
- 채점표(p.131): 요소 4개 × 3척도, 가짓수 차이형. 유의사항에 '고쳐쓰기'를 왜 별도 요소로 뗐는지 적었다.

### 2.3 수학(p.25–34, 167–191)

**재구조화 논리.**
- 원칙(p.28): 삭제한 학습 요소·성취기준은 없으나 **"약화시킬 수 있는 것"을 표시**; 중영역 안에서 함께 지도할 수 있는 것은 결합; 고등학교 연계 개념은 축소하지 않음; 재구조화 이유 = 원격수업 유용함 / 학습량 적정화 / 내용 연결 / 학습 결손 방지(각 이유의 뜻 표).
- 개관(p.29–32)에서 **재조정 = 문장을 좁혀 구체화**: "최대공약수·최소공배수의 성질을 이해하고 구할 수 있다" → "두 수를 소인수분해 하여 … 구할 수 있다"; "이차방정식을 풀 수 있고 활용하여 문제를 해결" → "이차방정식을 풀 수 있다"(활용을 뺌); "삼각비를 활용하여 여러 문제 해결" → "삼각비를 이용해 한 변의 길이를 구할 수 있다". → 이것은 우리 L-01(내용요소 삭제 금지)·L-02(C 문장보다 좁아지지 않게)와 **충돌**한다. 자료집도 "약화"라고 부른다. 우리는 따라가지 않되 §4-3처럼 '범위 메모'로 흡수한다.
- 영역별 상세(p.33–34): 중영역 소개 문단("제시된 순서대로 강한 위계성") → 표(이유 체크·[원격수업] 활동) → 〔해설〕에 **선수 학습 코드**([6수01-02], [6수01-03])와 연계 설명 → 〔교수·학습 유의사항〕·〔평가 유의사항〕에 **범위 제한**("복잡한 문제는 다루지 않는다").

**평가·기록 예시 가 「빙고를 활용한 일차방정식의 풀이」(p.167–177) — 유지 [9수02-05], 5차시.**

- 차시 표(p.168–169): 1차시 일차방정식 찾기 빙고(형성 1), 2~3차시 풀기 빙고(형성 2, 풀이 과정도 평가), 4~5차시 **학생이 실생활 문제를 만들고 다른 모둠 문제를 푸는** 수행(과제 3).

**평가·기록 예시 나 「이차함수의 그래프 그리기」(p.178–191) — 통합 [9수03-09/03-10], 6차시.**

### 2.4 사회(p.23–36, 100–113, 147–159)

**재구조화 논리.**
- 운영 원칙(p.23–24): 영역 내·단원 내 학습요소를 유기적으로 연결, 학년군 안에서 **지리·일반사회 영역 간 통합**도 시도(교과서가 사회1·2로 나뉘어 어렵다는 현실도 적음).
- 교수·학습 방향(p.24–25)에 실생활 연계 예(코로나 기본권 쟁점 토론), 선거 시뮬레이션, 랜선 답사, 모의재판 — 활동 아이디어 창고.
- 4단계 절차는 과학과 같다(p.30–31). 이유 표(p.31): 통합 = 학습량 적정화 / 내용의 연계, 재조정 = 기능의 연계 / 기능의 재조정, 유지 = 학습결손 방지 + **"그 교과의 성격을 잘 드러내는 성취기준은 통합하지 않고 유지"**(지도 읽기, 사회문제 탐구, 통합적 관점).
- 개관(p.31–36): 통합 문장이 **순서를 드러낸다** — "~을 파악한 후 ~이 미친 영향을 평가한다"(p.32 산지·해안), "~을 분석한 후 ~의 원인과 대책을 논의한다"(p.33 인구). 지리+일사 통합 `[9사(지리)04-03/(일사)02-02]`(p.33).

**수업 예시 나 「환경 문제 유발 산업의 국가 간 이전에 대해 자신의 의견 제시하기」(p.100–113) — 통합 [9사(지리)10-02/10-03], 3차시.** ★ 이번 판독에서 가장 좋은 단원.
- 해설(p.100)이 통합 근거(둘 다 '환경' 이슈, 학습량 적정화)뿐 아니라 **왜 사례를 교사가 주는지**(학생이 직접 조사하기엔 시간이 많이 든다)까지 적는다.
- 1차시(p.103–105): **핵심질문** "환경 문제는 지역적으로 평등하게 나타나는가?"를 먼저 띄우고 → NASA 위성 사진에서 "밝게 보이는 것은?" → "케냐 주민이 소비하려고 온실에서 장미를?" → "왜 유럽 농장이 케냐에?" → "장미 생산에 필요한 조건은?" → 교사가 다섯 조건으로 종합. **관찰 → 추론 → 추론 → 종합의 발문 사다리**. 이어 구글 어스로 네덜란드·케냐 위치·고도·공항 거리 확인(모둠 미션 ①~④, ④는 선택/심화).
- 우수 학생에게는 **다른 사례 자료**(전자쓰레기·석면 산업의 국제 이동)를 더 준다(p.105).
- 2차시(p.105–107): 영상 10분 → 장미 생산·수출 통계(출처) → **다섯 이해관계자 인터뷰**(유럽 수출업체·케냐 정부·주민·환경단체·농장 노동자; 자료 4개를 참고해 연구진이 쓴 **가상 인터뷰**, p.110–111) 읽기 → 잼보드에 '최대 이익/최소 이익' 축에 인물 붙이기 → 긍정/부정 영향 분류. 활동지 2(p.112)의 절차 안내가 4단계로 또렷하다.
- 3차시(p.108–109): 서술형 과제 = 장미 농장이 더 확대된다고 가정하고 **칼럼** 쓰기, <조건> 3개(지역적 불평등이 드러나게 / 긍·부정 영향을 구체 사례로 / 자기 의견에 이유). 활동지 3(p.113)에 칼럼 제목·날짜 틀. 출처: 교육부 2020 서·논술형 평가도구 자료집 사회 p.96–117 재구성.
- 피드백 세 갈래(p.108–109): ① 인터뷰에서 힌트 문구에 형광펜 → 키워드 관계 생각하기, ② **자기참조 피드백**("지난 시간보다 훨씬 논리적으로 썼네") — 성취기준 대비 뒤처짐이 아니라 이전 수행 대비 발전을 말함, ③ 다수가 필요하면 전체 피드백.
- 조건 ①("지역적 불평등이 드러나게")은 결론 방향을 미리 말한 셈이라 우리 C-32로는 **회색**이다. 조건 ②③은 지침형.

**평가·기록 예시 가 「일상생활 변화에서 찾은 사회 변동」(p.147–159) — 통합 [9사(일사)12-01/12-02], 5차시.**
- 차시 표(p.148–149): 1차시 형성 1(산업화·정보화·세계화 활동지), 2차시 형성 2(통계 두 개로 변화·원인·대응), 3차시 수행(사진 과거/현재 조사 보고서), 4~5차시 발표·즉시 피드백.
- 활동지 1(p.151): 정의문 (가)(나)(다)의 빈칸 → 각각 긍정/부정 측면 표. **학생 수준별 운영**(p.152): 상 = 바로 소모임에서 답안 비교, 중 = 자료 검색으로 미해결 과제 해결, 하 = **핵심 용어·특징이 적힌 재구성 활동지로 오픈북**.
- 활동지 3(p.153): 통계표 2개(출처) → 변화 모습 / 원인 / 대응 방안 칸. 운영 방안(p.154)에 "사회는 경험 교과"라며 **자기 삶 연결 질문**("내가 아이를 낳지 않는다면 그 이유는?")을 예시.
- 수행 활동지(p.155–156): 사진 선정 → 변동 요인 → (가)~(다) 중 어디인지 + 이유 → 변동 모습 설명 → 긍·부정 측면과 대응. 채점표(p.157)는 요소마다 **어느 활동지 문항에 해당하는지**(<보고서 1,2번>, <3,4번>, <5번>)를 적고, 2점 척도에 "(또는)"로 두 경우를 병기(wp9 C-36과 같은 관행).
- 채점 유의사항(p.157): 사전 안내 + 발표 직후 개별 피드백 + 분석적 채점.

### 2.5 영어(p.23–29, 74–86, 136–148)

**재구조화 논리.**
- 운영 원칙(p.23)에 **"반드시 재구조화해야만 하는 것은 아니다"** — 타당한 이유가 있을 때만 통합. 기본 어휘 학습 결손 방지.
- 평가 방향(p.25–26): 원격에서는 자료를 더 쓸 수 있으므로 단순 지식 확인보다 **분석·적용·판단**을 평가; 산출물의 범위·수준·내용을 구체적으로 제시; 과정을 관찰할 수 없는 과제는 기록 불가.
- 재구조화 원칙(p.29): 성취기준 문장을 **세 부분으로 분해**(소재의 범주·난이도 / 입력의 유형·수준 / 이해 기능의 위계)해 **같은 기능끼리**(듣기+읽기, 말하기+쓰기) 통합한다. 예: [9영01-04]+[9영03-04] → "말이나 대화를 듣거나 글을 읽고 줄거리·주제·요지를 파악". 핵심 개념·내용 요소·기능이 모두 남게.

**수업 예시 나 「친환경 제품 설명하기」(p.74–86) — 통합 [9영01-03/03-03] + [9영02-03/04-03], 중3, 11차시 → 8차시.**
- 해설(p.74): 이해 기능은 듣기/읽기 중, 표현 기능은 말하기/쓰기 중 **학생이 고르게** 해 선택권·내적 동기를 높인다.
- 흐름(p.75–76): 읽기 전(배경지식·학급 단어장·제목·삽화로 예측) → 읽기 중(요지·세부·요약) → 쓰기 전(언어 형식) → 쓰기/말하기 1단계(안내 + **채점 기준표 안내** + 브레인스토밍 + 초안) → 2단계(교사 피드백 반영 수정 → 같은 방식끼리 모둠 → 상호 피드백) → 정리(제출/발표 → 채점표로 최종 피드백 → 자기 평가).
- 유의사항(p.75): 확보한 차시 여유분은 형성평가·피드백·보완 과제에; 포스터·발표는 **내용 중심**으로, 같은 항목은 채점표로, 그 외는 구두로.
- 채점 기준표(p.81): 조건 충족(빠진 조건 수로 0/1/2~3/4+) · 내용 및 구성 · 언어 사용, 4단계(매우 우수/우수/보통/노력 요함).
- 꿀팁(p.83): 같은 내용을 듣기 자료와 읽기 자료로 **둘 다** 제공.

**평가·기록 예시 나 「소설을 읽고 결말을 창작하여 쓰고 발표하기」(p.136–148) — 통합 [9영02-01/04-01], 중3, 6차시.**
- 평가 요소 3개: 앞부분(원인) 추론 / 결말 창작 / 발표. 차시: 1 읽기(기억에 남는 문장 2개 공유) → 2 앞부분 추론 쓰기(개별 수행) → 3~4 결말 쓰기(릴레이 초안 → 공동 2고 → 최종고, 원고마다 수정 제안 2개) → 5~6 발표.
- 활동지 1(p.139–140): 발췌문(어려운 낱말 각주 3개) → 인물 설정 빈칸 틀(His job was… / He was … a person) → 자기 이야기 쓰기. 운영 방안: 원문 일부를 먼저 읽히는 까닭(기존 소설 모방 방지 + 쓰기 예시 제공); 이 과제는 **언어 형식보다 추론과 성실도** 위주로 채점.
- 채점표 1(p.141): 독창성 / 개연성 / 언어 사용, 유의사항에 "독창성과 개연성이 겹치지 않게 독립 채점".
- 채점표 2(p.144): **개인 평가**(과제 완성·내용)와 **모둠 평가**(개연성·창의성·내용·언어·완성) 분리; 언어 사용은 오류 개수(2개 이하/3~5/6)로.
- 과제 3(p.145–146): **학생 수준에 따른 과제** 상 = 암기 발표, 중 = 키워드 큐카드, 하 = 대본 — 보조 도구 차이를 채점표 '보조 도구 활용' 요소(3/2/1)에 반영. 발표 평가는 언어 형식을 빼고(이미 쓰기에서 평가) 유창성·발음·태도만. 피드백 장면 대본(교사 총평 → 학생 자기평가 → 동료평가)이 실려 있다.

## 4. 지침 제안 8건 (P = 프롬프트 문장, S = 스키마 칸; 전부 '지침'이며 검사(S)로 굳히자는 것은 없다)

표기: **[따라잡기]** = 공개 예시가 하는데 우리가 안 하는 것, **[예시보다 높이기]** = 공개 예시를 넘어서는 것(대표 요청 "공개 예시보다 조금 높은 수준").

### 2단계(재구성)

**G-1. 재구조화 해설 한두 문장 + 원래 차시 수 → 우리 차시 수** — [따라잡기] P+S
- 지침: `standards[]`마다 reason 태그는 그대로 두고 `reason_note`(1~2문장)를 더한다. 통합이면 **중심 코드**(어느 성취기준을 뼈대로 삼았는지)와 **매개 요소**(두 성취기준을 잇는 공통 기능·개념 — 예: '관점의 차이'·'주장과 근거의 타당성'), 유지면 **유지 이유**(핵심 개념이 서로 달라 연계성이 낮다 / 교과 성격을 드러내는 성취기준이다 / 다른 성취기준의 도구가 되어 결손 방지). `reconstruction` 옆에 `lesson_count_note`("교과서 기준 n차시 분량을 교수 5차시 + 평가 1차시로")를 둔다.
- 근거: 과학 p.48("[9과01-02] 중심으로 통합"), p.50(유지 이유), 국어 p.32–34(이유 칸이 문장), p.82(매개 요소), 사회 p.31(교과 성격 성취기준 유지), 과학 p.131·영어 p.74("5차시 → 3차시", "11차시 → 8차시").
- 왜: 지금 태그 3종은 학원 사정만 말하고 교육적 근거가 남지 않는다. 검토 AI가 fidelity를 판단할 때도 중심 코드가 있어야 "어느 원문 어휘로 썼는지" 대조가 쉽다.

**G-2. 학습 요소를 [지식]/[기능]으로 나누고 선수 학습 코드를 적는다** — [따라잡기] P+S
- 지침: `learning_elements`를 `{kind: "지식"|"기능", text}`로 태그한다(초등·중등 성취기준 문장의 "~을 알고/이해하고"는 지식, "~을 설명/비교/측정할 수 있다"는 기능). 세트에 선수 학습이 분명하면 `prerequisite_codes`(초등·중학 코드 1~3개)를 적는다.
- 근거: 과학 p.34–46([지식]/[활동] 두 묶음), 영어 p.29(소재·입력·기능 세 조각으로 분해해 같은 기능끼리 통합), 수학 p.34([6수01-02]·[6수01-03] 연계 해설).
- 왜: 3단계 퀴즈 수준(D~E 회상 = 지식, C·B = 기능)과 5단계 평가 요소("~하기")가 여기서 바로 나온다. 영어 세트는 '이해 기능 1 + 표현 기능 1' 짝이 보이게 된다.

**G-3. 재조정으로 문장을 좁히지 않는다. 대신 '세트 범위 메모'를 둔다** — [예시보다 높이기] P+S
- 지침: 공개 예시의 재조정은 활용·응용을 떼어 내는 **약화**다(수학 p.30 "이차방정식을 풀 수 있다", p.32 "한 변의 길이를 구할 수 있다"). 우리는 L-01·L-02를 유지해 reconstructed_text를 C 문장보다 좁히지 않는다. 다만 2단계에 `scope_note`(1~3줄)를 두어 **이 세트에서 다루는 범위와 다루지 않는 범위**("복잡한 활용 문제는 다루지 않는다", "변형은 교사가 주는 식까지"), 그리고 범위를 가르는 **용어의 뜻**("'간단한 일차방정식'은 등식의 성질 하나로 풀리는 것")을 적는다. 3단계 caution_notes·5단계 문항 난이도의 상한 근거가 된다.
- 근거: 수학 p.28("약화시킬 수 있는 것을 표시"), p.34(〔평가 유의사항〕 복잡한 문제 제외), p.167(각주 3 '간단한'의 정의와 "낮추어 제시"를 평가 의도에 명시).
- 왜: 범위를 문장에서 깎으면 성취기준 이탈이고, 안 적으면 5단계 문항이 C 도달점을 넘는 응용으로 튄다. 메모로 떼어 두면 둘 다 막힌다 — 이것이 공개 예시보다 한 단계 정직한 방식이다.

**G-4. 평가 요소 3~4개를 2단계에서 뽑고, 3단계 lesson_map에 '어느 차시가 어느 요소를 가르치는지' 표를 둔다** — [예시보다 높이기] P+S
- 지침: 2단계 `evaluation_elements_draft`("~하기" 3~4개, 과정 순서대로 — 공개 예시의 평가 요소 칸과 같은 꼴). 3단계 `lesson_map[]`에 `teaches_elements`(요소 번호 배열)를 더해 **성취기준 → 평가 요소 → 차시** 표가 되게 한다. 5단계 채점 요소는 이 초안을 따르되 바꿀 수 있고(바꾸면 references에 적는다), taught_in(C-39)은 이 표와 맞아야 한다.
- 근거: 과학 p.209·213(평가 요소 3개 → 과제 1~4 표), 국어 p.116·119(요소 4개 → 과제 1~3), 사회 p.147·157(채점 요소마다 <보고서 n번> 대응), 국어 p.116 평가 의도(과정 단계별로 요소 추출).
- 왜: 지금은 5단계가 끝나야 "어느 차시에서 가르쳤는가"가 드러난다(taught_in). 앞에서 정해 두면 3단계 활동이 요소를 빠뜨리지 않고, 공개 예시보다 더 나아가 **수준(level_ref)까지** 매핑된다.

### 3단계(차시 설계)

**G-5. 발문은 '추론 사다리'로 짜고, 회상 빈칸은 발문이 아니라 퀴즈로 보낸다** — [따라잡기] P
- 지침: teacher_script.questions 2~4개는 **자료 관찰(무엇이 보이는가) → 추론(왜 그런가·누가 그랬는가) → 종합·판단(그렇다면 무엇이 필요한가)** 순으로 잇고, 마지막 발문은 차시 핵심질문의 한 축에 닿게 한다. "빈칸에 들어갈 낱말은?" 꼴 회상 발문은 퀴즈 D~E 문항으로 보내고 발문에는 두지 않는다. if_stuck은 **발문마다 다르게** — 그 발문에 필요한 자료의 어느 부분·어떤 비교를 보라고 한 줄(일반 문구 "핵심 낱말에 밑줄" 반복 금지). 논제형 발문은 관점을 넓히는 꼬리 발문 1개(편의·안전 외에 일자리·윤리)를 붙인다.
- 근거: 사회 p.103(위성 사진 → 밝은 것 → 케냐 주민 소비? → 왜 유럽 농장 → 생산 조건 → 종합), 국어 p.80(자율주행 논제 관점 넓히기), 과학 p.134(그래프에서 '상대적으로 일정한 구간' 찾기). 우리 fixture 1차시 발문 1·2는 빈칸 회상.
- 검토 초점 추가 후보: "발문 2~4개가 모두 회상이거나 if_stuck이 두 차시 이상 같은 문장이면 level".

**G-6. 활동지는 발문·퀴즈와 다른 과제로, 한 장 안에 인지 진행 + 활동 도움말 + 수준별 지원·확장을 담는다** — [따라잡기 + 예시보다 높이기] P+S
- 지침:
  - tasks는 발문 prompt를 복사하지 않는다(검토: 발문과 같은 문장이면 other).
  - 기본(D~E) → 표준(C) → 도전(A~B)이 **같은 자료 위에서 인지 수준만 올라가게**: 용어 정의·확인 → 자료에서 사실 2~3가지 적기 → 판단·선택 + 이유(또는 두 사례 비교 + 기준).
  - 과제마다 `help`(학생용 활동 도움말 1~2줄, **질문형 절차**: "반복해서 나오는 낱말은?", "두 열을 견주면 무엇이 다른가?") — 답·수치·결론을 담지 않는다(C-32 '조건 ≠ 풀이 힌트'를 활동지에도 적용: 국어 p.120의 절차 질문은 되고, 초등 자료의 '(예: …)' 내용 힌트는 안 된다 — wp10 §3.2).
  - `support_low`(하 수준 지원 1개: 핵심 용어표·예시 1개·문장 틀) / `extend_high`(상 수준 확장 1개: 추가 사례 자료·조건 없이 추론·다른 방법으로 풀기) — 같은 과제에 붙는 지원과 확장이며 도전 과제와는 별개.
  - 도전 과제 유형에 **'결함 찾기'**를 허용: 교사가 일부러 틀린 풀이·통일성 어긋난 문단·오류 있는 기사 한 토막을 활동지 안에 넣고 학생이 찾아 고치게 한다(4단계 세트 자료가 아니라 활동지 전용 미니 자료 — 세트 자료 모순 금지 규칙과 충돌 없음).
- 근거: 과학 p.140–141(정의 → 사실 3 → 구간 → 선택+이유), 사회 p.155–156, 수학 p.184–186(❶~❺ 빈칸 탐구), 국어 p.120·123·127–128(♣ 활동 도움말), 국어 p.125·사회 p.152·수학 p.173·186·영어 p.145(상/중/하 운영), 과학 p.138·국어 p.125·사회 p.48(결함 찾기).
- '높이기' 부분: 공개 예시는 지원·확장이 운영 방안 문단에만 있고 활동지에는 없다. 우리는 활동지 칸으로 둔다.

**G-7. 차시마다 '확인·피드백 계획' 2~3줄을 둔다** — [예시보다 높이기] P+S
- 지침: `feedback_plan` = ① 이 차시 퀴즈·활동지에서 **무엇을 확인**하는지(다음 차시의 전제가 되는 것 1개 — 예: "가설이 '~하면 ~할 것이다' 꼴인지"), ② 틀린 학생에게 **다음 차시 전** 줄 피드백의 갈래(개별 / 모둠 / 전체, 각 한 줄), ③ **자기참조 문장 틀** 1개("지난 차시 활동지보다 ~이 늘었다"처럼 이전 수행 대비로 말하기 — 성취기준 대비 뒤처짐 말하기 금지), ④ 과정 점검 O/X 1개(활동 중간에 교사가 확인하고 넘어가는 지점). 7단계 안내장의 quiz_notes와 6단계 지침서 per_lesson이 이 칸을 받아 쓴다.
- 근거: 과학 p.135(다음 차시 전 확인·개별 피드백), p.137(옳고 그름보다 관찰 충실도), p.218(1차·2차 검토 O/X), 사회 p.108–109(힌트 형광펜 → 자기참조 → 전체 피드백 세 갈래, 예문), 국어 p.121(교사 평가 결과지의 진단 연쇄), 국어 p.135(발음·태도 피드백은 잘한 점 먼저).
- '높이기': 공개 예시는 피드백을 문단으로 풀어 쓴다. 우리는 퀴즈 level_ref(D~E/C/B)별로 누구에게 무엇을 줄지 한 줄씩 적게 해 원장이 그대로 쓰게 한다. G-05·G-08(채점 규칙)과 결이 같다.

**G-8. 마지막 교수 차시에 '채점 요소 공개 + 자기 점검표' 활동을 넣는다** — [예시보다 높이기] P
- 지침: 5차시 전개 소단계 하나(5~10분)를 "단원 평가에서 보는 것"에 쓴다: 5단계 채점 요소 이름(학생에게 보이는 그 이름, C-39)과 만점, 조건 종류(입장·근거 개수·형식·분량)를 보여 주고, worksheet.self_check를 그 요소에 맞춘 **자기 점검 문장**(요소마다 1개, "나는 자료의 수치를 단위와 함께 썼다")으로 쓴다. 답·결론·예시답안은 보여 주지 않는다(C-03). 산출물에 들어갈 **요소·가짓수**("근거 2개, 방안 개인 1·학교 1")를 명시한다.
- 근거: 국어 p.129("평가 실시 전 채점기준표를 제시"), 영어 p.76(5차시 '활동 절차와 채점 기준표 안내')·p.81(상호 피드백도 채점표 기준으로), 과학 p.219(산출물 평가 기준·척도 사전 공지, 요소·가짓수 명시).
- '높이기': 공개 예시는 채점표 전체를 보여 준다. 우리는 descriptor·예시답안은 가리고(5단계 규칙) 요소 이름과 가짓수만 보여 주어, 학생이 조건만 따라 쓰는 일(C-32 우려)은 피하면서 무엇이 채점되는지는 알게 한다. 3단계·5단계·7단계(criteria_phrases)가 같은 요소 이름을 쓰므로 일관성 검사도 쉬워진다.

### 채택하지 않은 관찰(기록만)

- 재조정으로 활용·응용을 떼는 약화(수학 p.30–32) — L-01과 충돌, G-3으로 대체.
- 모둠 산출 + 개별 채점 분리(영어 p.144, 국어 p.129) — 우리는 활동만 모둠, 답안은 개인(wp10 §4-9) 그대로.
- 표현 방식 학생 선택(영어 p.74) — 우리 단원 평가는 screen 글쓰기 고정. 차시 활동(발표/포스터)에서는 원장 재량.
- 가짓수형·"노력한다"형 척도(과학 p.219, 수학 p.175·189) — 5단계 **부정 예시**로만 쓸 수 있다(C-25·C-13).
- 세특 기재 예시(각 권 Ⅳ-4) — 학원에는 해당 없음. 단원 리포트(project-unit-report)와 결은 같으나 별도 작업.
- 원격 도구·45분·교과서 쪽 의존 — 전부 무시.

## 5. 3단계 프롬프트에 '참조 예시'로 넣을 만한 단원(과목별 2개) — 구조 요약만, 문장·자료는 옮기지 않는다

> 넣는 방식 제안: 과목별 1개를 10줄 구조 요약으로 넣고(≈600자), "이 흐름과 밀도를 참고하되 소재·자료·문장은 쓰지 않는다"는 한 줄을 붙인다. 생성 입력 상한(45k자)을 생각하면 과목당 1개가 적당하다. 2015 개정 코드는 적지 않는다.

### 국어
1. **「관점이 다른 글 읽고, 토론하기」 — 국어 p.75–84 (수업 예시, 중3, 5차시).** 왜: 영역 간 통합(읽기+듣말+쓰기)의 매개 요소를 명시한 유일한 예; 토론 개요서가 찬반 양쪽을 다 담는다.
   - ① 머리: 세 성취기준 → 통합 한 문장, 이유 체크, 주요 학습 요소 3개, 해설(각 성취기준의 초점 + 통합 문장의 중점).
   - ② 1~2차시: 토론 개념(영상) → 같은 화제 다른 관점 글 비교 → 문단별 핵심·필자 의견 차이 정리 → 나의 생각 쓰기.
   - ③ 3차시: 논제 용어 정리 → 논제·쟁점 정하기 → 관점 넓히는 교사 발문 → 자료 찾기.
   - ④ 4차시: 찬반 근거 모두 정리 → 개요서(상대 예상 주장·반론 포함) → 입장 택해 입론 쓰기 → 제출·댓글 피드백.
   - ⑤ 5차시: 역할(사회·찬·반·배심) → 토론 → 평가지(타당성·신뢰성·공정성)로 상호 평가 → 소감.
   - ⑥ 평가·피드백 메모가 차시마다 2줄(사고 과정 점검, 비난 금지 수칙).

   - ⑩ 주의: 자료는 학생이 찾는 구조 — 우리는 4단계 자작 자료 2개(상반 관점)로 바꿔야 한다.

### 수학

   - ⑩ 우리 대응: 퀴즈 B(관계·추론) 문항과 도전 과제('변형 없이')의 모델; 채점표는 우리 C-25로 다시 쓴다.

   - ⑦ 8차시: 제출/발표 → 채점표 최종 피드백 → 자기 평가.
   - ⑧ 채점표 3요소 × 4단계(조건 충족은 빠진 조건 수로).
   - ⑨ 꿀팁: 같은 내용을 듣기·읽기 둘 다 제공, 표현 방식 선택으로 동기.
   - ⑩ 우리 대응: S-영 세트의 5차시 흐름(G-8 사전 공개 + 초안 → 수정)의 원형; 자료는 영어판 자작(S-영-09).
2. **「소설을 읽고 결말을 창작하여 쓰고 발표하기」 — 영어 p.136–148 (평가·기록 예시, 중3, 6차시).** 왜: 앞부분 추론 → 결말 창작 → 발표의 사다리, 개인/모둠 평가 분리, 수준별 보조 도구.
   - ① 운영 계획: 통합 문장(묘사), 평가 요소 3개(원인 추론 / 결말 창작 / 발표).
   - ② 1차시: 작가 영상 → 발췌 읽기(어휘·어법·구조) → 기억에 남는 문장 2개 공유.
   - ③ 2차시 수행 1: 앞부분 추론 쓰기 — 발췌문(각주 3개) → 인물 설정 빈칸 틀 → 글. 언어 형식보다 추론·성실도.
   - ④ 3~4차시 수행 2: 실제 뒷부분 공개 → 릴레이 초안(한 사람 한 문장, 제한 시간) → 공동 2고 → 최종고 + 교훈 + 이렇게 쓴 이유; 원고마다 수정 제안 2개.
   - ⑤ 5~6차시 수행 3: 발표 연습 → 발표 → 교사 총평 → 자기·동료 평가 대본.
   - ⑥ 수준별: 상 암기 / 중 큐카드 / 하 대본 — 채점 요소 '보조 도구'로 반영.
   - ⑦ 채점표 1: 독창성·개연성·언어(독립 채점 유의). 채점표 2: 개인(완성·내용) + 모둠(개연·창의·내용·언어·완성; 언어는 오류 개수). 채점표 3: 유창성·발음·태도·보조 도구.
   - ⑧ 발표 평가에서 언어 형식 제외(쓰기에서 이미 평가).
   - ⑨ 피드백은 잘한 점 먼저.
   - ⑩ 우리 대응: 추론 → 창작 사다리는 S-영 논술형(narrative) 세트의 차시 뼈대; 모둠 창작은 활동만, 답안은 개인.

## 6. 쓸 때 주의할 점

- **저작권**: 수업 지원 목적 외 활용 금지 문구(각 권 끝). 프롬프트에는 §5 구조 요약만 넣고 활동지 문장·인터뷰·통계·발문 문장은 넣지 않는다. 기관명은 프롬프트에 쓰지 않는다(기존 관행).
- **2015 개정 코드**: 코드·성취기준 문장을 옮기면 우리 DB(2022 개정)와 어긋난다. 요약에 코드를 적지 않았다.
- **원격수업 맥락**: 도구·플랫폼·소회의실 운영은 전부 무시. '등교수업 대안'으로 적힌 활동이 오히려 우리 학원 교실에 맞는 경우가 많다(과학 p.134 등교 실험, 사회 p.107 포스트잇).
- **45분·모둠·학급 규모**: 분 배분은 우리 60분 틀로 다시 짠다. 모둠 활동은 2~4명 소규모 학원에서도 되지만 답안은 개인.
- **채점표 수준**: 공개 예시 채점표는 우리 C-12·C-13·C-25보다 약하다. 5단계 생성에 참고 예시로 넣지 않는다(이미 wp9·wp5 예시 은행이 더 낫다).

## 7. 대표님께 (짧게)
