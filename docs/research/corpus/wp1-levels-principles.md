# WP1 — 성취수준 원리 연구

> 목적: 평가원(KICE) 성취수준 개발 연구들을 읽고 "성취수준을 어떻게 정의·구분·기술하는가"의 원리를 추출하여, 다빈치스쿨 AI 파이프라인이 수준 문장·루브릭·등급표·피드백을 같은 문법으로(그리고 필요하면 더 낫게) 생성하도록 근거를 남긴다.
> 인용 표기: `(문서 약칭, p.쪽)`. 문서 약칭은 8번 표를 참조.

## 1. 성취수준의 정의와 용도, 단위

**정의.** "성취수준"은 학생들이 각 교과목 성취기준들에 도달한 정도를 나타낸 것으로, 도달 정도를 몇 개의 수준으로 구분하고 각 수준에 속한 학생들이 무엇을 알고 할 수 있는지를 기술한 것이다(총론, p.78; p.202). 즉 성취수준 = **수준 구분 표시(A~C/A~E) + 그 수준의 수행 특성 진술** 둘을 합친 개념이다(총론, p.78, p.202) — 표시만이 아니라 문장까지 포함한다는 점이 실무적으로 중요하다(우리 파이프라인이 "등급"과 "등급 설명문"을 분리해서는 안 되는 이유).

**두 개의 단위와 관계.**
- **성취기준별 성취수준**: 성취기준(문항 하나에 대응하는 최소 학습 단위) 단위로, 학교급·교과목 특성에 따라 3~5수준으로 구분·진술(총론, p.78, p.202).
- **영역별 성취수준**: 영역(또는 단원) 단위로, 영역 내 성취기준들을 포괄하는 전반적 특성을 3수준 또는 5수준으로 구분·진술(총론, p.78, p.202).
- **관계**: 영역별 성취수준은 성취기준별 성취수준들을 각 수준(A~E)별로 연계한 뒤, 지식·이해/과정·기능/가치·태도 범주를 중심으로 "포괄적이고 전형적인 능력"을 종합해 만든다 — 단순 나열이 아니라 재종합(총론, p.90, p.98). 나아가 성취기준별·영역별 성취수준을 수준별로 배열(같은 수준의 여러 영역을 나란히 놓기)하거나 영역별로 배열(한 영역의 A~E를 나란히 놓기)함으로써 교사가 "수준"과 "영역"에 대한 통일된 안목을 형성하도록 설계되어 있다(총론, pp.93–94).
- **용도(5가지, 활용방안 장 기준)**: ①성취기준 도달정도 예측/개념화 근거, ②학기단위 성취수준 개발 근거, ③학생 수준 고려 수업설계, ④평가도구 제작 및 채점기준 설정 근거, ⑤성취결과 산출·보고 근거(총론, p.141).

## 2. 수준 체계와 컷오프(성취율) 로직

| 학교급 | 수준 표시 | 수준 수 | 예외 |
|---|---|---|---|
| 초등학교 (전 교과) | A/B/C | 3 | — |
| 중학교 (체육·음악·미술 제외) | A/B/C/D/E | 5 (성취기준 특성에 따라 3~5로 축소 가능) | 체육·음악·미술은 A/B/C 3수준 |
| 중학교 체육·음악·미술 | A/B/C | 3 | — |
| 고등학교 보통교과 (국어·수학·영어·사회·역사·도덕·과학·기술가정·제2외국어 등, 수능/내신 5등급 산출 과목) | A/B/C/D/E | 5 | — |
| 고등학교 체육·예술·교양 (3등급 산출) | A/B/C | 3 | 일반고 '연극'도 3수준 |
| 고등학교 교양(P/F 산출 과목) | 영역별=P, 성취기준별=A/B/C | — | 성취기준별은 현장 평가도구 제작 편의상 3단계 유지 |
| 중·고 합본과목 — 정보·한문(수능 관련) | A/B/C/D/E | 5 | |
| 중·고 합본과목 — 보건·환경·진로와직업 | 영역별=P, 성취기준별=A/B/C(또는 3~5수준 가능) | — | |

(중등 성취수준 체계: 총론 p.78, p.203; 고등 체계: 고등 선택과목 총론 pp.41–42 표 Ⅲ-1-2; 중고 합본·고등 공통과목: 고등 공통·합본 총론 pp.44–45 표 Ⅲ-1-1.)

**성취율(컷오프) 로직 — 5수준 체계**
A 90%↑ / B 80%↑~90%미만 / C 70%↑~80%미만 / D 60%↑~70%미만 / E 40%↑~60%미만 (총론, p.80; 고등 두 총론 모두 동일표 반복, 고등 선택과목 총론 p.45, 고등 공통·합본 총론 p.48).

**성취율(컷오프) 로직 — 3수준 체계**
A 80%↑ / B 60%↑~80%미만 / C 40%↑~60%미만 (총론, p.81; 고등 동일).

**주의**: 이 성취율표는 "일반적 특성"(범교과 공통 앵커) 표에 붙은 참고 수치이며, 실제 문항별 정답률 목표치와는 별개의 메커니즘이다(§5의 "2/3 룰" 참조). 초·중·고 전체가 동일한 90/80/70/60/40, 80/60/40 컷오프 문구를 그대로 재사용한다 — 즉 KICE는 학교급을 초월해 하나의 "성취율 앵커"를 고정해두고, 그 위에 학교급별 문장 스타일만 바꾼다.

**"B가 A와 C 사이에 있다"는 것을 문장으로 어떻게 만드는가 — 세 축의 서술 전략**
- 지식·이해: 개념 위계(단순 암기 ↔ 깊은 위계)·이해의 깊이로 구분(총론, p.83, p.94, p.110).
- 과정·기능: 수행 정도 + 맥락/상황 변인의 복잡도(단순한 상황 ↔ 복잡한 상황, 단순 맥락 ↔ 다양한 맥락)로 구분(총론, p.83, p.110).
- 가치·태도: 내면화 정도 + 실천·참여 범위(좁은 적용/약한 실천 ↔ 넓은 적용/적극적 실천)로 구분(총론, p.83, p.110).
- 진술 전략(4가지 모두 확인됨): ①동사 자체를 바꾼다(평가하다>분석하다>조사하다>탐색하다, 사회과 p.93), ②동일 동사에 정도부사를 붙이되 "부사어만으로 위계화"하는 것은 지양(총론, p.103), ③조건절/제약절을 붙인다("주어진 자료에서", "안내된 절차에 따라", "제한된 여건에서" — 최소수준(C/E)에서만 제한적으로 허용, 총론, pp.101–102), ④범위·복합성을 줄인다(다양한 맥락→일부 맥락→단순한 상황).

## 3. 세 축(지식·이해/과정·기능/가치·태도)의 canonical 문장 패턴

**공통 문형(총론 Ⅳ-1 표, p.80~81)**
| 범주 | 동사·표현 계열 (높음→낮음) |
|---|---|
| 지식·이해 | 깊은 이해·높은 전이 → 이해와 전이 보통/다소 제한 → 위계 낮은 개념 일부 이해·습득 제한적 |
| 과정·기능 | 다양·복잡한 맥락에 적용, 매우 능숙 → 일부 맥락, 중간 수준/기본적 수행 → 기능 일부만 수행 |
| 가치·태도 | 내면화 가능, 적용 범위 매우 넓음 → 일부 조직화, 보통 → 일부 의미를 알고, 적용 범위 좁음 |

**국어과의 실제 동사 뱅크(도메인별로 다름, pp.93, 96, 99, 103)**
- 읽기: 낮음 "부분적으로 이해하고/일부 고려하며" → 높음 "이해하고/고려하여"; 과정·기능은 "부분적으로 파악/짐작" → "효과적으로/종합적으로 평가"; 가치·태도는 "긍정적으로 수용" → "적극적으로 참여".
- 문법: "확인한다" < "이해한다" < "분석한다" < "탐구한다"(중학교부터 최상위 수행으로 '탐구' 설정, p.98); 활용류는 "적절하게 활용" < "효과적으로 활용"(p.98); 가치·태도는 "관심" < "지님" < "내면화"(p.98).
- 문학: 높음 "다양하고 복잡한 상황을 여러 맥락에서 해결, 가치 내면화, 적극적 실천" / 낮음 "낮은 위계 지식 불완전 암기, 단순 상황, 협소한 적용, 소극적 실천"(p.102).

**과학과 — 5개 탐구기능 범주별 진술문 뱅크(표 Ⅴ-5, pp.83–84)**: 문제인식및가설설정 / 탐구설계및수행 / 자료수집·분석및해석 / 결론도출및일반화 / 의사소통과협업. 각 범주마다 "높음↕낮음" 예시 문장 쌍을 미리 만들어두고 성취기준에 맞게 골라 쓰는 방식(예: "선택한 문제 상황에 대한 가설을 설정할 수 있다"(높음) vs "자연현상과 일상생활에서 문제 상황을 말할 수 있다"(낮음)). 가치·태도도 별도 뱅크(과학의 심미적 가치/유용성/창의성/윤리성/개방성/안전·지속가능/문화향유, 표 Ⅴ-6, p.84)로 관리한다. **이 "미리 뱅크를 만들고 성취기준에 매칭"하는 방식은 우리 파이프라인이 그대로 채택할 수 있는 실무 패턴이다.**

**사회과 — 탐구기능 뱅크(표 Ⅴ-1~2, p.93)**: 자료수집(분석>조사>탐색), 자료검토(비판적으로 평가>비판적으로 분석>기준 제시>검토해야 함을 안다), 결론도출(합리적 결론 도출>결론 탐색>결과 열거), 문제해결(합리적 해결방안 제안>해결방안 분석>해결방안 조사). 가치·태도는 관심/자질태도/참여실천 3계열 × 상중하.

**역사과 — 인지 동사 위계(pp.40–41)**: 추론·분석 > 체계적 설명 > 제시/연결 > 사례를 말함 > 있었음을 말함. 예: "상관관계를 이해하고 자료를 수집하여 분석"(A) → "연결지어 파악하고 체계적으로 설명"(B) → "파악하고 제시"(C) → "사례를 말할 수 있다"(D) → "변화하였음을 말할 수 있다"(E).

**도덕과 — 수행동사 수준별 준거 용어표(표 Ⅳ-4, p.77)**: "이해하다"류(종합적으로 이해>다양한 측면에서 이해>이해>부분적으로 이해>일부 이해), "정당화하다"류, "비교·분석하다"류를 미리 5단 스펙트럼으로 고정해두고 성취기준마다 대입한다.

**통합교과 — Bloom 한국어 동사표(표 Ⅲ-2-3, p.39)**: 창조(도입/구성/개발/제안) > 평가(논박/평가/판단/설득) > 분석(분석/유형화/연결짓다) > 적용(적용/예측/구성) > 이해(연관짓다/분류/비교/설명) > 기억(정의/나열/기억해내다). 이 표는 총론·역사과·수학과·도덕과가 공통으로 인용하는 **Bloom(2001) 개정 교육목표분류 수행동사 위계**의 한국어판이며(원출처: 한국직업능력연구원 성취수준 개발 매뉴얼 2023, p.55) 전 교과 공통 참조자료로 기능한다(총론, p.104; 고등 선택과목 총론, p.51).

## 4. 과목별 특성 요약

| 교과 | 수준 구분 원리의 중심축 | 특이 규칙 |
|---|---|---|
| 국어 | 영역별(듣기말하기/읽기/쓰기/문법/문학/매체)로 축 비중이 다름 — 읽기·문학은 지식+과정+가치 균형, 쓰기는 과정·기능이 중심(성취기준 내 지식요소가 있어도 위계는 과정·기능에 있음, p.95), 문법은 단계형/병렬형/함축형 3가지 상세화 방식을 성취기준별로 혼합(p.97) | 초등 B·중학 C를 "성취기준 도달점"으로 고정하고 그 위/아래로 위계화(쓰기, p.95); 학교급간 연계 시 용어 통일(예: '국어생활' 통일, p.99) |
| 수학 | 과정·기능(계산·탐구·문제해결) 중심. 지식요소는 상대적으로 고정, 도달 여부의 차이는 맥락의 복잡성·전략 정교화로 표현 | 중2 이상에서만 다루는 '정당화'는 중1 이하 성취수준 진술에 쓰지 않음(p.43); 안내된 절차·구체적 조작활동은 D/E 수준에서만 허용(p.43); 성취기준 도달이 어려운 경우 E수준은 "일부만 도달"도 허용(중학 수학 고유, p.43) |
| 과학 | 지식·이해=Bloom 인지영역, 과정·기능=탐구 5범주(문제인식/설계/자료수집분석/결론도출/의사소통), 가치·태도=Krathwohl 정의적목표분류 기반 뱅크 | 서술어를 '~할 수 있다'로 통일, '안다'류 비외현적 동사 최소화, 부사/형용사만으로 수준 구분 금지, 교수학습방법('스마트기기 활용' 등)은 진술문에 넣지 않음, <탐구활동>을 성취수준 진술과 반드시 연계(pp.75–76) |

## 5. 평가 문항·채점기준과의 연결

**평가요소 → 채점요소 파이프라인(전 교과 공통 문구, 총론 p.164; 국어 p.135; 과학 p.150; 영어 p.111; 도덕 p.160 등 — 완전히 동일한 절차가 모든 교과 보고서에 복붙됨)**
```
성취기준+성취수준 분석 → 평가요소 선정 → 평가요소 고려해 평가방법 선정
→ 평가요소를 문항에 맞게 구체화해 채점요소 설정 → 채점기준 작성
```
평가요소 = "교육과정 성취기준 도달의 증거로 학생들이 보여주기를 기대하는 핵심 내용"(총론, p.164).

**"B 수준 문항"이 무엇을 의미하는가 — 통계적 정의**
지필 선택형 문항 제작 시 특정 수준에 편중되지 않도록 전 수준(A~E)에 걸쳐 문항을 배분하되, **"해당 성취수준 학생의 2/3 이상이 정답을 맞힐 수 있는 문항"**으로 설계한다(총론, p.167; 국어 p.137; 도덕 p.163 — 동일 문구 반복). 즉 "A수준 문항"이란 A수준 학생 2/3가 맞히고 B 이하는 그보다 낮은 정답률을 보이는 문항을 뜻하며, 중학교 예시에서는 실제로 같은 성취기준에 대해 난이도(수준)를 달리한 2개 문항을 나란히 개발해 이 원리를 보여준다(국어 pp.168–171: 한글맞춤법 성취기준에 대해 A/B 수준용 문항①과 E 수준 진단용 문항②를 별도 제작).

**채점기준표 = 채점요소 × 척도(점수) × 수행특성, 그리고 1:1 대응이 아니어도 된다는 것이 핵심**
- 채점요소는 평가요소를 문항에 맞게 구체화(총론, p.171).
- 성취수준(A~E)과 채점 척도(점수)는 **반드시 1:1 대응할 필요가 없다** — 예: 성취수준은 5단계라도 채점 척도는 3점 척도로 설계 가능(총론, p.172; 국어 p.138에도 동일 문구). 이는 루브릭 설계 시 등급 수와 배점 단계 수를 억지로 맞추지 않아도 된다는 명시적 허가다.
- 수행특성은 "성취기준별/영역별 성취수준을 고려해 학생이 보여주어야 할 수행능력을 채점요소별로 기술"(총론, p.173).
- **예시답안 구성 원리**: 각 수준의 예시답안은 해당 채점요소의 수행특성 문장을 구체적 과제 맥락(예: 계절의 아름다움 감상 활동)에 대입해 만든다. "감상"·"좋아하는 이유" 같은 정의적 요소는 맞고 틀림이 없으므로, 학생 표현이 "정당하고 이해할 만한 수준"이면 도달로 간주 — 즉 서·논술형 채점은 정오 판정이 아니라 정당화 가능성 판정이라는 원칙이 명시됨(총론, p.175, 초등 통합교과 즐거운생활 감상 예시).

**평가도구 개요 템플릿(모든 교과 공통, 총론 p.171~172, 국어 p.137~139 등)**: 학교급/과목/학년군/영역/성취기준/성취기준별 성취수준/평가요소/평가도구유형/배점/(정답)/개발방향 및 활용 시 고려사항/문항/(정답해설 또는 채점기준표+예시답안). — **이 필드셋을 WP2/WP3 스키마의 뼈대로 그대로 재사용 가능.**

## 6. 고등 A~E와 초·중의 차이, 합본과목 처리

- **일반적 특성표(성취율 90/80/70/60/40, 80/60/40)는 초·중·고 전부 동일 문구를 그대로 재사용**한다(고등 선택과목 총론 pp.44–45; 고등 공통·합본 총론 pp.47–48). 즉 "고등학교라서 더 어렵게 잡는" 별도 컷오프 체계는 없다 — 학교급 차이는 컷오프가 아니라 **과목 수·과목 구조(선택과목 체계)**와 **성적 산출 정책(내신 5등급제/3등급제/P-F)**에서 발생한다.
- **어떤 과목이 5단계/3단계/P인지는 교육과정 내용이 아니라 "2028 대학입시제도 개편"에서 정한 내신 산출 방식이 원인**이다(고등 선택과목 총론 p.42, 고등 공통·합본 총론 p.43) — 국어·수학·영어·사회·역사·도덕·과학·기술가정·제2외국어(일반선택)=5단계, 체육·음악·미술·교양=3단계(교양은 P), 이는 성취수준 개발 논리가 아니라 성적표기 정책에 종속된 설계라는 뜻.
- **최소성취수준 보장지도**: 고등학교는 과목이수제(학업성취율 40% 이상 + 출석률 2/3 이상)가 적용되어, E(또는 최저 수준)의 진술이 "이수/미이수" 판정과 직결된다(영어과 초중 보고서, p.111에서 고등 정책을 소개). 초·중은 미이수 제도가 없고 기초학력 보장 차원의 활용에 그친다(총론, p.164) — **고등의 최저수준 문장은 초·중보다 정책적 무게가 훨씬 크다.**
- **합본과목(정보·한문·보건·환경·진로와직업)**: 중학교와 고등학교에 같은 과목명이 있고 한 편의 보고서로 개발됨. 정보·한문은 수능/내신에 편입되므로 A~E 5단계, 보건·환경·진로와직업은 P(영역별)+A~C(성취기준별, 현장 평가도구 제작 편의 목적)로 개발(고등 공통·합본 총론, pp.44–45). 개발 절차는 초중 총론과 완전히 동일한 4단계(내용요소 추출→위계화→수준분석→위계점검)이며 교과 특유의 상세화만 추가된다(같은 문서, pp.56–62 보건과·국어과 예시).
- **고등 공통과목(공통국어1·2, 공통수학1·2, 통합사회1·2, 한국사1·2, 통합과학1·2 등)**은 중학교 이후 첫 고등 과목이라는 위상 때문에 초중 교과서와 동일한 진술 지침·Q&A·Bloom 참조표를 그대로 준용하되(같은 문서 p.44 각주), 내용체계 자체가 통합형(예: 통합과학의 '과학의 기초' 신설 영역, 같은 문서 p.42)이라 영역 분석 단계에서 재구성이 필요하다는 점이 다르다.

## 7. 우리 파이프라인에 넣을 규칙안 (근거 포함)

1. **수준 문장은 반드시 "표시(A~E)"와 "수행특성 문장" 세트로 생성한다** — 등급 기호만 있고 문장이 없거나, 문장만 있고 등급이 없는 산출은 KICE 정의를 위반한다(총론 p.78, p.202 근거).
2. **성취기준별 수준 문장은 원 성취기준 대비 "동일한 도달 정도"의 재진술이지, 서로 다른 학습 내용의 나열이 아니다** — A/B/C/D/E는 각기 다른 과제가 아니라 하나의 성취기준에 대한 도달 정도 차이다(총론 p.101, 고등 두 총론 Q&A 동일). 생성 시 5개 문장이 서로 다른 활동을 지칭하지 않는지 검증 규칙으로 넣는다.
3. **중간 수준(3수준의 B, 5수준의 C)을 "성취기준 원문에 가장 가까운 도달점"으로 고정하고, 그 위/아래로 위계화한다** — 국어 쓰기·읽기·문학의 실제 사례가 이 패턴을 취한다(p.91, p.95, p.102). 성취기준 문장을 그대로 특정 수준(특히 낮은 수준)에 복붙하는 것은 금지(총론 p.101, 두 고등 총론 Q&A④).
4. **성취기준 진술을 상/B(A/B) 수준에 그대로 베끼지 않는다** — 대신 "추가·확장된 정도"로 제한한다(총론 p.101 Q&A③). 우리 생성기에 "A 수준 문장 ≠ 성취기준 문장 + 수식어 0개" 체크를 넣는다.
5. **최하위 수준(초 C, 중·고 E)에 학습량을 과다하게 얹지 않는다** — 최소성취수준은 정책 활용도가 높으므로 과대 요구를 지양(총론 p.104–105, 두 고등 총론 Q&A⑥). 생성기에서 최하위 등급 문장의 길이·요구 요소 수가 최상위 대비 과도하게 많으면 경고.
6. **부사·형용사만으로 등급을 차별화하지 않는다** — "정확하게/다양한" 같은 표현으로만 등급을 가르는 것은 원칙적으로 지양하고, 동사(수행 동작 자체)·범위·조건절로 위계를 만든다. 부득이하면 교과별로 부사 사용 규칙을 먼저 고정한 뒤 전 등급에 일관 적용한다(총론 p.103, 과학 p.75 — "부사·형용사만으로 구분 금지"는 특히 강한 규칙).
7. **조건절("주어진 자료에서", "안내된 절차에 따라", "제한된 여건에서")은 최하위 등급에서만, 그것도 제약을 설명해야 할 때만 제한적으로 사용한다** — "동료와 교사의 도움을 받아"류는 개인 수행능력을 흐리므로 권장하지 않는다(총론 p.102, 고등 두 총론 Q&A⑥).
8. **가치·태도 항목은 모든 등급에 강제로 채우지 않는다** — 일부 등급에서만 나타나도 되고, 3단계(A~C)만으로 구분해도 된다. 다만 "A에만 있고 나머지는 없음"처럼 있다/없다 이분법으로 떨어뜨리지 않는다(총론 pp.99–100, 두 고등 총론 Q&A①②). 파이프라인의 가치·태도 필드는 optional-but-graded로 설계.
9. **영역별 수준 문장은 성취기준별 문장들의 단순 병합이 아니라 재종합이다** — 지식·이해/과정·기능/가치·태도 세 범주로 나누어 각각 포괄적으로 다시 쓴다(단, 역사처럼 병합형을 명시적으로 택한 과목도 있으므로 과목 설정으로 전환 가능하게 만든다)(총론 p.90, p.98; 역사 p.42).
10. **문항 난이도 ↔ 성취수준 연계는 "해당 수준 학생 2/3 정답률" 기준으로 체크한다** — 우리 문항 생성 후 난이도 태깅에 이 정량 기준을 메타데이터로 남긴다(총론 p.167).
11. **루브릭 척도 수와 성취수준 단계 수를 억지로 맞추지 않는다** — 5단계 성취수준이어도 3점 채점척도로 축약 가능(총론 p.172). 우리 채점기준 생성기는 "성취수준 단계 수"와 "채점 척도 수"를 별도 파라미터로 분리한다.
12. **채점기준표 필드는 KICE 템플릿(학교급/과목/학년군/영역/성취기준/성취기준별 성취수준/평가요소/평가도구유형/배점/개발방향및고려사항/문항/채점기준·예시답안)을 그대로 스키마화**한다(총론 pp.171–172).
13. **정의적(가치·태도) 문항의 채점은 정오가 아니라 "정당화 가능성"으로 판단한다** — 학생 표현이 맥락상 타당하면 도달로 인정하는 원칙을 서·논술형 자동채점 프롬프트에 명시한다(총론 p.175).
14. **과목별 동사 뱅크를 미리 구성해두고 성취기준에 매칭하는 방식(과학·사회·도덕에서 확인)을 표준 워크플로로 채택** — LLM이 매번 동사를 새로 창작하지 않고, 교과×범주×등급의 3차원 동사 사전에서 고르게 한다(과학 pp.83–84, 사회 p.93, 도덕 p.77).
15. **학교급 간 연계(나선형 배열) 검증 스텝을 넣는다** — 동일 성취기준 계열이 학년군이 올라가며 위계가 커지는지, 용어가 통일되어 있는지(예: '국어생활') 확인하는 규칙 기반 체크(국어 p.99, 총론 pp.89, 96).
16. **고등학교 세트 생성 시 "성적산출 방식(5단계/3단계/P)"을 먼저 조회해 등급 스킴을 자동 분기**한다 — 이는 교육 내용이 아니라 정책 테이블이므로 하드코딩된 매핑 테이블(§6 표)로 관리한다.
17. **최소성취수준(고등 E) 생성 시 "과목이수제 40% 컷"이라는 정책 맥락을 프롬프트에 주입**해, 지나치게 낮거나 지나치게 관대한 최저 기준이 나오지 않게 한다(영어 p.111).
18. **합본과목(정보/한문/보건/환경/진로와직업) 세트는 중·고 두 학년대 성취기준을 한 세트로 개발한다는 전제를 스키마에 반영**한다 — 별개 세트로 쪼개면 KICE 원 설계와 어긋난다(고등 공통·합본 총론 p.44).
19. **가독성 검증**: 이해하기 쉽고 간결/명확한지, 만연체·모호한 표현이 없는지, 학생이 "못하는 것"이 아니라 "할 수 있는 것" 중심으로 긍정문으로 쓰였는지 자동 체크(총론 p.97, p.99).
20. **"한다"/"할 수 있다" 서술어는 교과 단위로 하나로 통일**하되, 흥미·태도류 내용요소는 예외적으로 "~을 가진다"류를 허용한다(총론 p.104, 두 고등 총론 Q&A⑤).

## 8. 자료를 넘어설 지점 후보

1. **가치·태도의 측정가능성 문제**: 도덕과 연구진 스스로 "내면화하는 자세"를 5단계로 위계화하는 것에 회의를 표명했다(p.73). KICE는 결국 "3단계로 낮추거나 전 등급에 강제하지 않는다"는 완화책으로 봉합했는데, 우리는 더 나아가 가치·태도를 **행동 증거 기반 루브릭(관찰 가능한 행동 지표 체크리스트)**으로 재정의해 서·논술형 자동채점이 "내면화 여부"가 아니라 "글에 드러난 행동/관점 진술"을 판정하도록 설계할 수 있다. KICE 방식은 교사의 장기 관찰을 전제하지만 우리 파이프라인은 단발 채점이 많으므로 이 간극을 메워야 한다.
2. **초-중-고 연속성의 구조적 단절**: 초등 3단계 ↔ 중등 5단계 ↔ 고등 5/3/P 체계가 다르고, 컷오프 성취율표는 동일 문구를 재사용하지만 실제 "위계가 더 커지는지"에 대한 정량적 근거는 문서 안에 없다(정성적 점검만 언급, 총론 pp.89, 96). 하나의 교과·영역이 초→중→고로 이어질 때 등급 간 "실질 난이도 갭"이 일정한지 확인할 방법이 없다 — 우리는 학년군 간 문항 캘리브레이션(공통 채점 기준 문항, 앵커 문항)을 두어 이 연속성을 실증적으로 검증하는 절차를 추가할 수 있다.
3. **영역 통합/STEAM형 세트에서의 수준 판정 공백**: 현재 체계는 교과-영역 단위로만 수준을 정의하며, 여러 교과·영역이 결합된 융합 문항(예: 수학+과학+사회 통합 서논술형 세트)에 대한 수준 판정 원리는 전혀 다루지 않는다. 우리 파이프라인이 다교과 융합 세트를 만들 계획이라면, "복수 성취기준의 수준을 어떻게 하나의 종합 등급으로 합성할지"에 대한 자체 규칙(예: 최솟값 규칙 vs 가중평균 규칙)을 새로 설계해야 한다.
4. **문항 난이도의 "2/3 정답률" 기준의 실증성 부재**: 이 규칙은 설계 원칙으로만 제시되고, 실제 파일럿에서 검증된 통계치가 보고서에 없다(총론 p.167 — "예측하는 것"이라는 표현 자체가 사전적 가정임을 시사). 우리는 실제 채점 데이터가 쌓이면 이 2/3 규칙을 경험적으로 보정하는 피드백 루프(생성된 문항의 실측 정답률로 난이도 태그 재조정)를 추가할 수 있다.
5. **부사 회피 원칙과 실제 예시 간의 긴장**: 과학·총론 모두 "부사/형용사만으로 구분 금지"를 명시하면서도, 실제 예시 문장 다수는 사실상 정도부사(다양한, 종합적으로, 매우)에 의존한다(예: 과학 p.83 "매우 능숙함" 등). 원칙과 실행 사이 간극이 있다는 뜻이며, 우리 자동 검증기는 "동사가 바뀌었는가"와 "부사만 바뀌었는가"를 구분하는 실질적 휴리스틱(예: 동사 원형 비교, 목적어/범위 명사구 비교)을 만들어야 한다 — 단순히 "부사 사용 금지" 키워드 필터로는 부족하다.
6. **채점기준의 척도-등급 비대응 원칙이 낳는 하위 설계 공백**: "5등급이어도 3점 척도 가능"이라는 원칙(총론 p.172)만 주어지고, 등급→척도 매핑을 어떻게 결정할지(예: A/B를 5점에, C/D를 3~4점에, E를 1~2점에 매핑할지)에 대한 알고리즘은 없다. 우리는 교과·문항유형별 매핑 정책을 명시적 설정값으로 두고, 근거(어떤 등급 경계를 척도 경계와 합칠지)를 로그에 남기는 방식으로 이 공백을 메울 수 있다.
