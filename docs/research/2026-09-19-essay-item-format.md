## 1. 공통작성양식의 정확한 구조 (JSON 스키마 도출용)

문서는 3부로 구성: **Ⅰ. 저자 안내 메일**, **Ⅱ. 빈 양식**, **Ⅲ. 작성 예시(수학·연립방정식)**.

### 1-1. 항목 구성 (총 11개 항목 + 표지)

| 번호 | 항목 | 비고 |
|---|---|---|
| (표지) | 교과(과목) / 학년·학기 / 대단원·소단원 / 문항 유형(서술형·논술형·혼합형 체크박스) / 예상 소요 시간(분) / 집필자 성명 / 작성일·최종수정일 | |
| 1 | 성취기준 (원문) | `[성취기준 코드]`, `[원문]`, `[관련 핵심역량]` |
| 2 | 성취기준 재구성 | 표: 원문 성취기준 / 성취기준의 재구성(`학생은 ___을(를) 활용하여 ___을(를) ___할 수 있다.`) / 핵심질문(학생이 품을 질문 1개) |
| 3 | 학습요소 추출 (3차원 분류) | 지식·이해 / 과정·기능 / 가치·태도 |
| 4 | 평가 목표 | `교사는 학생의 ___을(를) 통해 ___을(를) 판단한다.` — **학생이 무엇을 쓰는가가 아니라 교사가 무엇을 판단하는가**로 작성 |
| 5 | 과제 상황 (수행 맥락) — **선택 항목** | 누가/누구에게/왜/어떤 자료로/어떤 결과물로. 실생활·역할극형일 때만 작성, 아니면 "해당 없음" |
| 6 | 자료 (지문·이미지·도표) | 표: 자료 번호/형태/내용 요약/출처/저작권 처리 상태(자작·공공누리·허락받음·인용) + 저작권 체크리스트 3문항 |
| 7 | 평가 문항 (학생 제시용) | `[과제 상황 제시문]`(3~6줄) → `[자료]` → `[문항1](__점)` → `[문항2](__점)` → `[응답 조건]`(분량/필수 포함 요소/작성 형식) |
| 8 | 출제 의도 | "무엇을 측정하려 하는가" + "어떤 사고 과정을 끌어내고자 하는가" 2개 소항목 |
| 9 | 통합 루브릭 (평가 요소 + 채점 기준) | 표 형태, 평가요소 행 × 점수 열(5~1점 등). 요소 수 3~5개 권장, 단계 수 3~6단계, **자율 조정 가능** |
| 10 | 총체적 채점 기준 | **반드시 상/중/하 3단계** (요소 수와 달리 이 부분은 고정), 각 수준 5~7줄 서술 |
| 11 | 예시 답안 | 상/중/하 수준별 전문(분량 조건 충족하는 완성된 글) |

### 1-2. 필수 준수 규칙 (원문 그대로)
- "모든 항목은 빈칸으로 두지 마시고, 해당되지 않는 경우 '해당 없음'이라고 명시"
- "모든 서술의 종결어미는 '~다' 평서문으로 통일"

- 자료 출처·저작권 처리 상태 반드시 표기(상업 출판 필수 요건)

- 제출: 한글(.hwp), 파일명 `[과목]_[학년]_[단원]_[집필자명]_v[버전].hwp`

## 2. 루브릭 구조 (관찰된 3가지 변형)

1. **공통양식 표준**: 분석적 루브릭(평가요소 3~5개 × 5~1점, 라벨 "매우 우수~매우 미흡") + 총체적 채점기준(상/중/하 고정, 5~7줄) + 예시답안(상/중/하 전문). 배점 합계는 문항마다 다름(10/16/20점 등).
2. **방법론 책 실제 사례(국어·과학)**: 문항이 여러 개(문항1·2·3…)일 때 **문항별로 분석적 루브릭을 따로** 만들고 배점도 문항마다 다르게 배분(예: 5/4/4/4점 또는 10/10점). 총체적 채점기준은 세트 전체에 대해 상/중/하 하나로 통합.
3. **박소현 영어 샘플(공통양식 확정 전 버전으로 추정)**: 분석적 루브릭이 4~0점(5단계) 스케일이며, 총체적 루브릭은 상/중/하가 아니라 **A/B/C/D + 점수구간(9~10, 7~8, 4~6, 0~3)**을 사용 — 공통양식의 "총체적 채점 기준은 반드시 상·중·하 3단계" 규정과 **불일치**. 최종 표준화 이전 자료로 보임(주의 필요, §6 참조).

공통점: 예시답안은 항상 "유일한 정답이 아니라 하나의 가능성"으로 제시하며, 상/중/하(또는 등급) 답안 예시를 함께 제공.

## 3. 방법론(『성취기준에서 문항까지』)의 단계 시퀀스와 정의

서론에서 9단계로 명시(원문 소제목 그대로):

1. **성취기준 원문 읽기: 문항 개발의 출발점** — 성취기준을 "내용 범위"로만 보지 않고, **핵심 기능어**(설명한다·비교한다·파악한다·추론한다·주장한다·감상한다·창작한다 등 "학생이 수행해야 할 중심 활동을 드러내는" 동사)를 먼저 찾고, 그 기능이 연결된 대상을 확인. 관련 핵심역량도 함께 확인.
2. **성취기준 재구성: 학생의 실제 수행으로 바꾸기** — "재구성이란 성취기준을 임의로 축소·변형하는 일이 아니다… 원문의 취지를 유지하되, 학생이 실제 평가 상황에서 무엇을 읽고 파악하며 어떤 방식으로 사고·표현해야 하는지를 보다 분명하게 드러내는 작업." 4원칙: ①본질 이탈 금지 ②수행 행동 명시 ③단순 확인 아닌 사고과정 포함 ④이후 핵심질문·자료·문항·루브릭과 연결.
3. **핵심질문 만들기** — "학생이 자료를 읽고 나서 반드시 붙잡아야 할 중심 문제"이며 "문항이 요구하는 사고의 수준을 결정." 사실 확인형 질문(예: "이 자료의 내용은 무엇인가")은 약하고, 비교·추론·판단을 유도하는 질문이 좋음.
4. **자료 설계: 학생의 사고를 이끄는 장면 만들기** — 자료는 "사고의 출발점"이지 장식이 아님. 너무 단순/친절하면 사고를 대신해버리고, 너무 복잡하면 핵심질문에서 벗어남. "자료는 학생에게 단서와 맥락을 제공하되, 최종적인 판단과 서술은 학생 자신의 몫으로 남겨 두어야 한다."
5. **문항 설계: 읽기에서 서술까지의 흐름 만들기** — 읽기→이해→비교/추론→판단→서술의 흐름을 자연스럽게 구성. 조건은 "평가에 꼭 필요한 수준"으로 제한.
6. **평가 목표와 출제 의도** — 평가 목표="무엇을 평가할 것인가"(교사 관점), 출제 의도="왜 이렇게 설계했는가"(설계자 관점).
7. **루브릭 구성** — 분석적 루브릭(요소별 세분화)과 총체적 루브릭(상·중·하 전체 수준)은 "대체 관계가 아니라 보완 관계."
8. **예시답안 구성** — "정답을 제시하기보다 좋은 답안의 구조를 보여 주기" 위한 것. 상/중/하 각각의 특징(자료 반영·근거·논리 전개의 정도 차이)을 예시.
9. **마지막 점검** — 재구성이 원문 취지를 벗어나지 않았는지, 핵심질문이 사고를 유도하는지, 자료가 사고를 대신하지 않는지, 문항이 읽기→서술 흐름을 담는지, 루브릭이 문항과 일치하는지 자체 점검.

### ※ 용어 매핑 관련 주의
사용자가 예상한 "성취기준 → 핵심 기능어 → **수행방법** → **산출물** → 재구성 → 핵심질문 → 차시 → 문항 → 루브릭" 흐름 중 **"수행방법", "산출물", "차시"라는 용어 자체는 이 책의 방법론 챕터(1~14쪽)에서 명시적으로 정의되지 않음.** 대신:
- "산출물"에 해당하는 개념은 공통양식 5번 "과제 상황"의 **"어떤 결과물로"** 필드로 구현됨(도슨트 해설문, 소식지 설명문 등).
- "수행방법"은 별도 항목이 아니라 "과정·기능"(3번 학습요소) 및 "문항 설계" 단계에 녹아 있음.
- "차시"는 방법론 책 서론에서 전혀 언급되지 않음(수업 차시 배분은 다른 자료에 있을 가능성 — 대단원/소단원 필드만 존재).
파이프라인 설계 시 이 용어들이 **다른 사내 문서(예: 별도 커리큘럼 설계서)에서 온 것인지, 혹은 재정의가 필요한지 소유자에게 확인 필요.**

## 4. 구체적 문항 예시 (요약)

### 예시 A — 수학 (공통양식 Ⅲ부, 중2, 연립방정식) — "학교 정원 설계"
- 성취기준: [9수02-13] 미지수 2개 연립일차방정식 풀이·활용
- 과제 상황: 학생이 "학교 정원 설계 학생 위원" 역할, 정원 둘레 30m·넓이 54㎡ 조건 제시
- 문항1(6점): 변수 설정 후 연립방정식 세우기(서술 포함) / 문항2(9점): 풀이 + 해의 타당성 3문장 이상 서술
- 응답조건: 200자 내외, 필수요소(변수설정/두 식/풀이과정/해의 해석)
- 루브릭: 4요소(변수설정및식세우기/풀이정확성/해석및타당성/서술논리성) × 5단계, 20점 만점; 총체적 상/중/하; 예시답안 3단계(상: "x=9,y=6…정원 설계에 적절하다" / 중: 풀이만 / 하: 답만 나열)

### 예시 B — 국어 (방법론 책, 문학 감상) — "도슨트 해설문"
- 성취기준: [9국05-01] 운율·비유·상징의 효과를 감상·창작
- 과제 상황: "학교 도서관 시화전 학생 도슨트"가 되어 관람객에게 김영랑 「돌담에 속삭이는 햇발」의 비유·운율 효과를 3~4문장으로 해설
- 조건: 2연의 비유 원리+작품 전체 운율 형성 원인 모두 포함, 대화체(~습니다/~해요)
- 루브릭: 4요소(비유이해/운율파악/표현적절성/창작적절성) × 5단계(4~0점), 16점 만점; 예시답안 상(12점)/중(7~8점)/하(5점 이하)로 **점수 구간까지 명시**한 점이 공통양식보다 한 단계 더 구체적

(참고로 `수학 서논술형 예시문항.pdf`의 "황금비" 문항, 박소현 샘플의 영어 "발명품 소개" 문항도 동일한 요소 구성을 따름 — 과제상황→문항 1~n→응답조건→루브릭(분석적+총체적)→예시답안.)

## 5. 관찰된 제약 조건

- **분량**: 원고 전체 A4 6~8쪽(공통양식). 학생 응답 분량은 문항 세트마다 상이(200자 내외~900자 내외, 3~4문장~14문장 이상) — 학년·과목·문항 개수에 따라 자유롭게 설정되는 것으로 보이며 고정 규칙은 발견되지 않음.
- **조건(응답조건) 형식**: 항상 "분량 / 필수 포함 요소 / 작성 형식" 3단 구성이 반복됨. 과학 문항처럼 "서술 순서"(자료분석→원리설명→결론)까지 지정하는 경우도 있음.
- **자료 제시 방식**: 텍스트, 표, 인포그래픽(이미지), 시 원문 등 다양. 자료마다 출처·저작권 상태 명기 필수. 자작 자료가 압도적으로 많음(교과서 자료 재사용 금지 원칙 — 저작권 체크리스트 1번 "교과서 자료가 아닌 새 자료인가").
- **학년별 차이**: 표지에 학년/학기 필드는 있으나, 표준양식 자체에는 학년별 분기 규칙이 없음. 실제 사례 비교 시 고학년(고1 과학)일수록 문항 수가 많고(3~4문항 세트) 배점·분량이 커지는 경향(과학과 예시는 20점 만점, 800~900자)만 관찰됨 — 공식 규칙은 아님.
- **문항 배점 합계**: 10/16/20점 등으로 문항 세트마다 다름. 공통양식엔 "___점 만점"으로 빈칸 처리되어 있어 고정값 없음.
- **과제 상황(5번)**: 선택 항목이며, 과학 문항 중 일부는 "해당없음"으로 처리(예: 주기율표 문항, 세포호흡 문항의 "누가/누구에게" 필드).

## 6. 파이프라인 설계자가 owner에게 확인해야 할 질문

1. **총체적 루브릭 등급 표준**: 공통양식은 "상/중/하 고정"을 명시하지만, 박소현 샘플은 A/B/C/D+점수구간을 사용함. AI가 생성할 최종 산출물은 어느 쪽이 맞는가? (공통양식이 더 최신 버전으로 보이나 확인 필요)
2. **"수행방법", "산출물", "재구성", "차시"라는 용어가 정확히 어느 문서에서 정의되는가?** 이번에 검토한 방법론 책 서론(1~14쪽)에는 해당 용어가 명시적으로 등장하지 않음 — 다른 사내 자료(커리큘럼 설계 문서 등)가 따로 있는지 확인 필요.
3. 문항 세트당 **총 배점의 표준값**이 있는가, 아니면 문항 수·난이도에 따라 자유인가?
4. 학생 응답 분량(자수·문장수) 기준을 **학년/과목별로 표로 정리한 사내 규정**이 있는가, 아니면 매번 집필자 재량인가?
5. **과제 상황(5번) 작성 여부를 AI가 자동 판단**해야 하는데, 어떤 성취기준 유형(예: 문학/실생활 활용형)일 때 필수로 넣을지 규칙이 있는가?
6. 하나의 문항 세트에 문항이 여러 개(문항1~4)일 때, **분석적 루브릭을 문항별로 쪼갤지 세트 전체로 통합할지** 표준이 있는가(방법론 책 사례는 문항별로 쪼갠 경우가 많음).
7. 최종 산출물 포맷은 `.hwp` 제출이 확정인가, 아니면 AI 파이프라인은 `.docx`/JSON 중간 산출물까지만 책임지고 hwp 변환은 별도 공정인가?
8. AI가 생성한 자료(지문·표 등)의 저작권 처리 상태는 항상 "자작"으로 표기해도 되는가, 별도 법무 검수 절차가 필요한가?
9. 성취기준 원문 데이터베이스(교육과정 코드 전체 목록)를 AI가 참조할 공식 소스가 있는가?
