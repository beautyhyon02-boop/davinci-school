## 성취기준 코드 형식에 대한 메모
과제 지시의 정규식 `\[\d+사\(?[가-힣]*\)?\d{2}-\d{2}\]`(사회)·`\[\d+역\d{2}-\d{2}\]`(역사)는 **중학교 사회·역사** 코드에만 맞는다. 실제로 처리한 자료 다수가 **고등학교** 과목이며, 고등학교는 과목별로 표기 체계가 다르다:
- 통합사회 `[10통사04-01]`, `[10통사1-05-02]`, `[10통사2-01-01]` (학기·단원 세분 표기가 붙기도 함)
- 세계지리 `[12세지02-02]`, 한국지리 `[12한지01-02]`, 경제 `[12경제04-01]`
- 한국사 `[10한사1-02-01]`, `[10한사03-05]` / 동아시아사 `[12동사04-01]`
- 정치와 법 `[12정법03-02]`

이 코드들은 모두 원문에 인쇄된 그대로 옮긴 것이며, 정규식 위반이 아니라 **정규식이 고등학교 과목을 다루지 않아서** 발생한 불일치다(검증 스크립트로 51건 확인, 모두 고등학교 과목 코드). 향후 스키마의 표준코드 정규식을 확장할 때 참고할 수 있도록 여기 기록한다.

## 중복(dedupe) 확인
- **서울 "중고등학교 사회과 서·논술형 평가도구 자료집"(2022)과 교육부 "사회과-서·논술형 평가도구 자료집"(2020)**: 지시문은 "may duplicate — dedupe by stem"이라 하였으나, 실제 대조 결과 완전히 별개의 자료집(발행연도·집필진·사례 목록이 다름)이며 문항 중복이 없었다. 유일하게 단원명이 같은 "세계 시장과 교역"(서울본 11번)도 내용은 환율(경제)로 교육부본(비교우위·무역정책)과 다르다 → 중복 아님, 별도 파일로 보존.
- **가이드북(중/고) 2021의 "동일 파일 2부"**: `index.json`에 파일명이 `..._2021.txt`와 `..._가이드북_2021.txt`로 두 벌 등록되어 있으나 해시(`2cd1600e`, `cc3826f9`)가 동일한 **완전 동일 사본**이므로 한 벌만 처리했다.
- 그 외 파일 간 문항 중복은 발견되지 않음(자료집 8종이 각기 다른 성취기준·소재를 사용).

## 읽기 어려운 페이지
표(채점기준표)를 포함해 모든 대상 페이지의 텍스트 레이어가 온전했다. **PNG 렌더링이 필요했던 페이지는 없음.** 다만 "수업과 연계한 사회과 서·논술형 평가실천하기"(서울, 자료 7)의 시장경제 단원 일부 문항(구글 설문/이미지 기반, 텍스트 46–53쪽 부근)은 실제 문항 이미지(그래프·시나리오 카드)가 텍스트로 추출되지 않아, 채점기준표에 서술된 체크리스트 문구를 근거로 문항 내용을 재구성했다는 점을 해당 레코드의 context에 명시했다.

## 사회 서·논술형 문항에서 관찰한 5가지 특징 (프롬프트 설계에 참고할 점)

1. **자료(자극) 유형이 매우 다양하고 "실제 자료"를 선호한다.** 통계표·그래프·지도뿐 아니라 신문기사, 헌법재판소·대법원 판결문, 사료(고종실록·삼국사기·비문), 구술 인터뷰, 영화 대사, 정치 포스터, 심지어 유튜브 동영상 캡션까지 활용된다. 같은 사회 현상을 다루더라도 "제도 설명 글 + 실제 사례 기사 2~3개"의 조합이 표준 패턴이며, 학생에게 익숙한 소재(햄버거, 최저임금, SNS)로 성취기준을 감싸는 경우가 많다. → 프롬프트는 자료 유형을 다양화하고, 최소 1개는 시사성 있는 실제/유사 사례를 포함하도록 지시해야 한다.

2. **조건(<조건>)이 매우 세분화되어 있고, 조건 하나하나가 배점과 1:1 대응한다.** "A와 B를 각각 서술할 것", "○○ 용어를 포함할 것", "500자±50자로 쓸 것", "자료의 내용을 그대로 옮기지 말 것"처럼 조건이 채점 요소를 그대로 예고한다. 조건이 많을수록(3~5개) 배점도 세분화되고, 조건이 없을수록(예시자료집 다수) 총체적 채점(우수/보통/향상필요)으로 흐른다. → 프롬프트에서 조건을 만들 때는 채점 요소와 1:1 대응하도록 설계하고, 글자 수 조건은 가급적 ±50자 허용 범위를 명시해야 한다.

3. **배점은 정답 요소의 "개수"에 선형적으로 대응하는 조건-점수형이 압도적으로 많다.** "3가지 중 2가지 서술 시 부분점수"처럼 요구 항목 개수와 점수가 정비례하는 구조가 기본값이며, 예시 답안은 만점·부분점수·0점 각각에 대해 실제 오답에 가까운 학생 답안까지 제시해 채점자 간 편차를 줄인다(2인 이상 채점 권고 사례도 있음). 반면 성취수준(교육과정성취수준) 자료와 서논술형 예시자료집 계열은 A~E(또는 상/중/하) **총체적 채점**을 쓰며, 요소별 척도가 아니라 "수행 특성"을 문장으로 기술한다. → 정량적 조건-점수형과 정성적 총체적 채점형을 모두 지원하도록 채점표 스키마를 유지하고, 둘 중 어느 쪽을 쓸지는 문항의 조건 개수에 따라 자동 판단하는 규칙을 프롬프트에 넣을 수 있다.

4. **채점 시 유의점(notes)에 "정답으로 인정할 수 있는 대안적 표현"을 명시적으로 열어둔다.** "정확한 법률 용어를 못 써도 의미가 통하면 인정", "예시 답안과 다르더라도 논리적으로 타당하면 정답 처리", "핵심 키워드가 없어도 취지가 같으면 인정"이라는 문구가 거의 모든 채점기준표에 등장한다. 이는 서·논술형 채점이 "정답 매칭"이 아니라 "논리 구조 판단"임을 뜻한다. → 자동 채점 프롬프트에는 반드시 "표현이 달라도 논리가 같으면 인정"하는 유연성을 채점 지침에 넣어야 하며, notes 필드에 이런 대안 인정 기준을 옮겨 적어 둔 것이 그 근거다.

5. **가치·태도(정의적 영역)는 "찬반 의견+근거 2개 이상"이나 "성찰적 자기 서술" 형태로, 정답이 없는 논술형에 배치된다.** 의무투표제·잊힐권리·시민불복종·문화상대주의·최저임금 인상처럼 사회적으로 논쟁적인 주제에서는 어느 입장을 택했는지가 아니라 "근거의 논리성·자료 활용 여부"만 채점하고, 입장 자체에는 점수를 매기지 않거나 선택 여부에만 1점을 준다. 또한 정치 참여 단원에서는 "내가 맡은 역할"에 감정이입해 주장하게 한 뒤, 마지막 총괄 논술형에서 자신의 활동을 메타적으로 성찰(한계·개선방안 도출)하게 하는 2단계 구조(역할 몰입 → 성찰적 글쓰기)가 반복된다. → 가치·태도 문항을 생성할 때는 "입장 자체"가 아니라 "근거의 타당성·자료 연계성"을 채점 기준의 핵심으로 삼고, 정치·사회 참여 단원에서는 역할극 후 메타 성찰 단계를 짝지어 설계하는 것이 이 자료들의 공통 패턴이다.
