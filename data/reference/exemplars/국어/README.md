## 다섯 가지 관찰 — 프롬프트 설계에 참고할 점

1. **자료(제시문) 길이는 목적에 따라 크게 갈린다.** 단답형에 가까운 서술형은 200~400자 내외 지문(설명문 발췌, 짧은 시)으로 충분한 반면, 논술형·비교형 문항은 300~1,500자 지문 2~4개(예: 시+평론+비교 대상 시, 신문기사+통계+인터뷰 3~4종)를 동시에 제시하는 경우가 많다. 특히 "복수 자료 통합형"(찬반 자료, 두 작품 비교)이 절반 가까이를 차지해, 제시문 1개만 주는 방식은 실제 관행과 다르다.
2. **`<조건>`의 개수는 2~4개가 표준이며, 조건이 곧 채점 기준의 뼈대가 된다.** 조건 수 분포는 2개(25건)·3개(16건)·4개(11건)가 대다수였고, 조건이 아예 없는 문항(16건)은 대개 "본문에서 찾아 쓰시오"류의 단순 확인형 서술형이었다. 조건은 거의 예외 없이 "내용 조건"(무엇을 포함할지)과 "형식 조건"(문장 형태·분량·인용 방식)으로 나뉘어 제시되며, 채점표의 배점도 이 구분을 그대로 따른다.
3. **배점은 서술형 2~9점, 논술형 4~16점이 주류이나, 프로젝트 수업과 결합된 총괄평가에서는 서술형도 26점까지 치솟는다.** (예: 오픈북 지필고사에서 설명 방법 4가지를 모두 적용하라는 문항.) 배점이 세분화될수록 평가 요소도 그만큼 잘게 쪼개지므로(예: 4개 설명 방법 × [적용 4점+문장완성도 1점]), 고배점 문항일수록 하위 채점 요소를 명확히 분리해 제시하는 경향이 뚜렷하다.
4. **루브릭 스타일은 압도적으로 "분석적"(59건)이며, "분석-총체 혼합"(16건, 분석적 채점표 + A/B/C 총체적 설명을 나란히 제공)도 상당수다.** 순수 "총체적"이나 "체크리스트형"(제시/미제시, O/X)은 형성평가·말하기 평가처럼 즉각적 피드백이 목적인 경우에 국한된다. 분석적 채점 기준은 거의 항상 "채점 요소별 배점 → 척도별 기대 수행(상/중/하 또는 점수별) → 예시 답안"의 3단 구조를 따른다.
5. **피드백은 정답 여부를 넘어 "학생이 무엇을 다음에 해야 하는지"까지 구체적으로 서술한다.** 대부분의 자료가 수준별(상/중/하) 피드백 예시 문구를 별도로 제공하며, 공통적으로 (1) 잘한 점을 먼저 언급 → (2) 부족한 점을 채점 기준 언어로 정확히 지적 → (3) 구체적 학습 활동을 제안하는 3단 구성을 취한다. 특히 "채점 시 유의사항"이 "예시 답안과 다른 표현이라도 의미가 통하면 정답 인정" 같은 유연성 지침을 거의 모든 문항에 포함하고 있어, AI가 채점 기준을 생성할 때도 예시 답안을 유일한 정답으로 못박지 않는 관용적 태도를 함께 학습해야 함을 시사한다.
